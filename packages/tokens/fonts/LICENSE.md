# 마루부리 (MaruBuri)

- 저작권자: NAVER Corp.
- 출처: https://hangeul.naver.com/font/maru-buri
- 원본 배포본: `https://hangeul.naver.com/hangeul_static/webfont/zips/maruburi.zip` (OTF/TTF)

이 디렉터리의 `.woff2` 파일은 위 공식 배포본의 OTF를 웹 사용을 위해 woff2로 변환한
것입니다. 글자 모양(아웃라인)은 변경하지 않았습니다.

마루부리는 네이버가 무료로 배포하며 개인·기업 상업적 이용이 가능합니다. 폰트 파일
자체를 유료로 판매하는 것은 금지됩니다. 정확한 조건은 위 출처의 라이선스 안내를
따릅니다.

## 담긴 굵기

| 파일 | font-weight |
| --- | --- |
| `MaruBuri-Regular.woff2` | 400 |
| `MaruBuri-SemiBold.woff2` | 600 |
| `MaruBuri-Bold.woff2` | 700 |

원본은 ExtraLight(200)·Light(300)까지 5종이지만, 이 앱이 쓰는 3종만 담았습니다.
