옵저버 패턴은 객체의 상태 변화를 관찰하는 구독자들에게 자동으로 알림을 보내는 패턴입니다.

```javascript
class EventEmitter {
  #listeners = {};

  on(event, callback) {
    (this.#listeners[event] ??= []).push(callback);
    return () => this.off(event, callback); // unsubscribe 함수 반환
  }

  off(event, callback) {
    this.#listeners[event] = this.#listeners[event]?.filter(cb => cb !== callback);
  }

  emit(event, ...args) {
    this.#listeners[event]?.forEach(cb => cb(...args));
  }
}

// 사용
const emitter = new EventEmitter();
const unsub = emitter.on('dataChanged', (data) => console.log(data));
emitter.emit('dataChanged', { id: 1 });
unsub(); // 구독 해제
```

**프론트엔드 사례:**
- DOM 이벤트 리스너 (addEventListener)
- React의 상태 관리 (Redux의 subscribe)
- RxJS의 Observable
- Node.js의 EventEmitter
