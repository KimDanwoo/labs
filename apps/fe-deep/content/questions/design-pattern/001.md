싱글톤 패턴은 클래스의 인스턴스가 오직 하나만 생성되도록 보장하는 패턴입니다.

```javascript
// JavaScript 모듈 자체가 싱글톤
// api-client.js
class ApiClient {
  constructor() {
    this.baseURL = '/api';
  }
  get(url) { return fetch(this.baseURL + url); }
}

export const apiClient = new ApiClient(); // 모듈은 한 번만 실행

// 클래식 싱글톤
class Database {
  static instance;
  static getInstance() {
    if (!Database.instance) {
      Database.instance = new Database();
    }
    return Database.instance;
  }
}
```

- JavaScript 모듈 시스템(ES Modules)이 자연스러운 싱글톤 역할을 합니다.
- 전역 상태 관리(store), API 클라이언트, 로거 등에 사용됩니다.
- 테스트가 어려워질 수 있으므로 의존성 주입(DI)과 함께 사용하는 것이 좋습니다.
