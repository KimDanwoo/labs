두 패턴 모두 React에서 컴포넌트 로직을 재사용하기 위한 패턴입니다.

```typescript
// HOC (Higher-Order Component)
function withAuth<P>(WrappedComponent: React.ComponentType<P>) {
  return function AuthComponent(props: P) {
    const user = useUser();
    if (!user) return <Redirect to="/login" />;
    return <WrappedComponent {...props} user={user} />;
  };
}
const ProtectedPage = withAuth(Dashboard);

// Render Props
function MouseTracker({ render }: { render: (pos: Point) => ReactNode }) {
  const [pos, setPos] = useState({ x: 0, y: 0 });
  // ... mouse tracking logic
  return render(pos);
}
<MouseTracker render={({ x, y }) => <div>위치: {x}, {y}</div>} />
```

- 현대 React에서는 **Custom Hook**이 두 패턴을 대부분 대체합니다.
- HOC: 인증 체크, 에러 바운더리 래핑 등에 여전히 사용
- Render Props: 유연한 렌더링 위임이 필요할 때
- Custom Hook이 가장 간결하고 합성이 쉬우므로 우선적으로 사용합니다.
