App Router의 Metadata API는 **페이지별 메타데이터를 선언적으로, 타입 안전하게** 관리하는 방법입니다.

### **정적 / 동적 메타데이터**

- 내용이 고정된 페이지는 **`metadata` 객체를 export**해서 title, description, openGraph 등을 선언합니다.
- 데이터에 따라 달라지는 페이지(상세 페이지 등)는 **`generateMetadata` 함수**를 export합니다. params로 데이터를 조회해 제목과 설명을 만들어 반환하면 됩니다.

### **레이아웃과의 관계**

메타데이터는 **layout에서 기본값을 정의하고 개별 page에서 오버라이드**하는 계층 구조입니다. `title.template`을 레이아웃에 두면 하위 페이지 제목이 "페이지명 | 서비스명" 형태로 일관되게 조합됩니다.

### **SEO 최적화 전략**

메타 태그 외에 파일 컨벤션으로 SEO 요소를 함께 관리합니다.

- **sitemap.ts** — 동적으로 사이트맵을 생성해 크롤러에게 URL 목록을 제공합니다.
- **robots.ts** — 크롤링 허용/차단 경로를 선언합니다.
- **opengraph-image** — SNS 공유 카드 이미지를 페이지별로 동적 생성할 수 있습니다.
- **JSON-LD 구조화 데이터** — FAQ, 브레드크럼 같은 스키마를 삽입해 검색 결과에 리치 스니펫이 노출되게 합니다.
- **canonical·alternates** — 중복 URL의 대표를 지정하고 다국어 페이지를 연결합니다.

핵심은 서버 렌더링된 HTML에 **크롤러가 JS 실행 없이 읽을 수 있는 완성된 메타데이터**가 담겨 나간다는 점입니다.
