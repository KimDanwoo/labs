Server Actions는 **클라이언트에서 직접 호출할 수 있는 서버 함수**입니다. `'use server'` 지시어로 선언하며, API Route를 따로 만들지 않고도 폼 제출이나 데이터 변경 같은 서버 로직을 실행할 수 있습니다.

### **어떻게 쓰는가**

- **폼과 연결** — form의 action에 Server Action을 넘기면, 제출 시 FormData가 서버 함수로 전달됩니다. 함수 안에서 DB에 쓰고 `revalidatePath`로 관련 화면을 갱신하는 흐름이 전형적입니다.
- **Client Component에서 호출** — 버튼 클릭 등 이벤트 핸들러에서 일반 함수처럼 호출할 수 있습니다. `useTransition`으로 감싸면 처리 중 상태를 표시할 수 있고, `useOptimistic`과 조합하면 서버 응답 전에 UI를 먼저 바꾸는 낙관적 업데이트도 가능합니다.

### **장점**

- **별도 API 엔드포인트가 필요 없습니다.** 엔드포인트 정의, 요청 코드, 타입 맞추기가 사라집니다.
- 폼과 연결하면 **JavaScript가 로드되기 전이나 비활성화 상태에서도 제출이 동작**합니다(Progressive Enhancement).
- 서버에서만 실행되므로 시크릿 접근이 안전합니다.

### **주의**

클라이언트에서 호출 가능한 **공개 엔드포인트가 생기는 것과 같으므로**, 함수 안에서 입력 검증과 권한 확인을 반드시 해야 합니다. "내 컴포넌트에서만 부르니까 안전하다"는 가정은 성립하지 않습니다.
