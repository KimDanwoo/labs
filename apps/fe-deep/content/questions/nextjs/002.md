App Router에서 컴포넌트는 **기본이 Server Component**이고, 상호작용이 필요한 곳에만 `'use client'`를 선언해 Client Component로 만듭니다.

### **Server Component**

**서버에서만 실행**됩니다. DB 쿼리나 파일 시스템에 직접 접근할 수 있고, 그 코드는 **클라이언트 JS 번들에 포함되지 않습니다.** 무거운 라이브러리를 서버에 두면 번들이 그만큼 줄어듭니다.

대신 **상태와 이벤트를 가질 수 없습니다** — useState, onClick, 브라우저 API는 사용할 수 없습니다.

### **Client Component**

파일 상단에 `'use client'`를 선언하면 됩니다. 상태·이벤트·브라우저 API를 쓸 수 있는 대신, 코드가 **클라이언트 번들에 포함되고 hydration 대상**이 됩니다.

### **핵심 원칙**

- **Server Component를 기본**으로 쓰고, 상호작용이 필요한 최소 범위에만 `'use client'`를 붙입니다.
- `'use client'`는 그 지점 **아래 전체를 클라이언트로** 만들므로, 트리의 말단(leaf)에 붙일수록 번들이 작아집니다.
- Client Component 안에서 Server Component를 **import할 수는 없지만**, `children`으로 전달받는 것은 가능합니다. "클라이언트 래퍼가 서버 콘텐츠를 감싸는" 구조가 이렇게 만들어집니다.
