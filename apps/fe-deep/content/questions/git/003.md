각각 다른 상황에서 변경 사항을 관리하는 데 사용됩니다.

```bash
# reset: 커밋을 되돌림 (히스토리 변경)
git reset --soft HEAD~1   # 커밋만 취소 (변경사항 staged)
git reset --mixed HEAD~1  # 커밋+staging 취소 (변경사항 unstaged)
git reset --hard HEAD~1   # 모든 변경사항 삭제 (주의!)

# revert: 새 커밋으로 이전 커밋을 되돌림 (히스토리 유지)
git revert abc1234        # abc1234의 변경을 취소하는 새 커밋

# stash: 임시로 변경사항을 저장
git stash                 # 현재 변경사항 임시 저장
git stash pop             # 저장한 변경사항 복원
git stash list            # 저장 목록 확인
```

- **reset**: 로컬에서 실수를 수정할 때 (push 전)
- **revert**: 이미 push된 커밋을 안전하게 되돌릴 때
- **stash**: 브랜치 전환 시 미완성 작업을 임시 보관할 때
- `--hard` reset은 데이터 손실 위험이 있으므로 신중하게 사용해야 합니다.
