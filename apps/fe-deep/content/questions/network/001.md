HTTPS는 HTTP에 TLS(Transport Layer Security) 암호화를 추가한 프로토콜입니다.

- **HTTP**: 데이터가 평문으로 전송되어 도청/변조 위험이 있음 (포트 80)
- **HTTPS**: TLS로 암호화되어 안전하게 전송 (포트 443)

**HTTPS 동작 과정:**
1. 클라이언트가 서버에 연결 요청
2. 서버가 SSL 인증서(공개키) 전송
3. 클라이언트가 인증서 검증
4. 대칭키를 교환하여 암호화 통신 시작

- SEO에서 HTTPS가 우대받으며, 최신 브라우저 API(Service Worker, Geolocation 등)는 HTTPS에서만 동작합니다.
- HTTP/2, HTTP/3은 기본적으로 HTTPS를 전제합니다.
