각 HTTP 메서드는 리소스에 대한 특정 동작을 나타냅니다.

| 메서드 | 용도 | 멱등성 | 요청 바디 |
|--------|------|--------|----------|
| GET | 리소스 조회 | O | X |
| POST | 리소스 생성 | X | O |
| PUT | 리소스 전체 수정 | O | O |
| PATCH | 리소스 부분 수정 | X | O |
| DELETE | 리소스 삭제 | O | X |

```
GET    /api/users          → 사용자 목록 조회
POST   /api/users          → 새 사용자 생성
GET    /api/users/1        → 1번 사용자 조회
PUT    /api/users/1        → 1번 사용자 전체 수정
PATCH  /api/users/1        → 1번 사용자 일부 수정
DELETE /api/users/1        → 1번 사용자 삭제
```

- **멱등성(Idempotent)**: 같은 요청을 여러 번 보내도 결과가 동일한 성질
- GET 요청은 캐싱이 가능하며, POST는 캐싱되지 않습니다.
- RESTful API 설계 시 적절한 메서드를 사용하는 것이 중요합니다.
