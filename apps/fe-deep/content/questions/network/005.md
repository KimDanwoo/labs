HTTP 캐싱은 네트워크 요청을 줄여 성능을 향상시키는 핵심 메커니즘입니다.

**Cache-Control 헤더:**
```
Cache-Control: max-age=3600          # 1시간 캐시
Cache-Control: no-cache              # 매번 서버에 검증
Cache-Control: no-store              # 캐시하지 않음
Cache-Control: public, max-age=86400 # CDN에서도 캐시 가능
Cache-Control: private               # 브라우저만 캐시
```

**검증 메커니즘:**
- **ETag**: 리소스의 해시값. 변경 여부를 서버에 확인
- **Last-Modified**: 마지막 수정 시간 기반 검증

```
# 첫 요청
응답: ETag: "abc123"

# 재요청
요청: If-None-Match: "abc123"
응답: 304 Not Modified (변경 없으면 바디 없이 응답)
```

- 정적 파일(JS, CSS)은 파일명에 해시를 포함하고 `max-age`를 길게 설정하는 것이 일반적입니다.
- Next.js는 빌드 시 자동으로 파일명 해싱을 처리합니다.
