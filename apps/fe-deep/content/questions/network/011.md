CDN(Content Delivery Network)은 전 세계 엣지 서버에 콘텐츠를 캐싱하여 전달합니다.

**동작 원리:**
1. 사용자가 리소스 요청
2. DNS가 가장 가까운 엣지 서버로 라우팅
3. 엣지 서버에 캐시가 있으면 즉시 응답 (Cache Hit)
4. 없으면 오리진 서버에서 가져와 캐싱 후 응답 (Cache Miss)

**프론트엔드 최적화 효과:**
- **TTFB 감소**: 물리적으로 가까운 서버에서 응답
- **대역폭 절감**: 오리진 서버 부하 분산
- **가용성 향상**: 오리진 장애 시에도 캐시된 콘텐츠 제공

**캐싱 전략:**
```
# 정적 자산 (JS, CSS, 이미지) - 장기 캐싱
Cache-Control: public, max-age=31536000, immutable

# HTML 페이지 - 짧은 캐싱 + 재검증
Cache-Control: public, max-age=0, must-revalidate

# API 응답 - 캐싱 안 함
Cache-Control: private, no-store
```

**Next.js + Vercel:**
- 정적 페이지: 자동으로 엣지 캐싱
- ISR: stale-while-revalidate 패턴 적용
- Image Optimization: 엣지에서 이미지 변환/캐싱

- 파일명 해싱(`main.abc123.js`)으로 장기 캐싱 + 캐시 버스팅
