WebSocket은 클라이언트와 서버 간 양방향 실시간 통신을 위한 프로토콜입니다.

| 특성 | HTTP | WebSocket |
|------|------|-----------|
| 통신 방향 | 단방향 (요청-응답) | 양방향 |
| 연결 | 비연결성 | 지속 연결 |
| 오버헤드 | 매 요청마다 헤더 | 초기 핸드셰이크만 |
| 용도 | 일반 웹 통신 | 실시간 데이터 |

```javascript
// WebSocket 클라이언트
const ws = new WebSocket('wss://example.com/ws');

ws.onopen = () => {
  ws.send(JSON.stringify({ type: 'subscribe', channel: 'chat' }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('수신:', data);
};

ws.onclose = () => console.log('연결 종료');
```

- **사용 사례**: 채팅, 실시간 알림, 주식 시세, 온라인 게임
- **대안 기술**: SSE(Server-Sent Events), Long Polling
- Supabase Realtime도 내부적으로 WebSocket을 사용합니다.
