Mocking은 테스트에서 외부 의존성을 가짜 객체로 대체하는 기법입니다.

```typescript
// API 호출 모킹
jest.mock('./api', () => ({
  fetchUser: jest.fn().mockResolvedValue({ id: 1, name: 'Kim' }),
}));

test('사용자 정보 표시', async () => {
  render(<UserProfile userId="1" />);
  await waitFor(() => {
    expect(screen.getByText('Kim')).toBeInTheDocument();
  });
});

// 모듈 모킹
jest.mock('next/navigation', () => ({
  useRouter: () => ({ push: jest.fn(), back: jest.fn() }),
  useSearchParams: () => new URLSearchParams(),
}));

// 타이머 모킹
jest.useFakeTimers();
jest.advanceTimersByTime(1000);
```

**Mocking이 필요한 경우:**
- API 호출 (네트워크 의존 제거)
- 타이머/날짜 (결과 예측 가능하게)
- 브라우저 API (localStorage, window 등)
- 외부 라이브러리

- 과도한 Mocking은 테스트의 신뢰도를 떨어뜨리므로 주의해야 합니다.
- MSW(Mock Service Worker)는 네트워크 레벨에서 API를 모킹하는 인기 도구입니다.
