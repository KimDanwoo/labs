Storybook은 UI 컴포넌트를 **독립적으로 개발하고 문서화**하는 도구입니다.

**Story 작성:**
```tsx
// Button.stories.tsx
import type { Meta, StoryObj } from '@storybook/react';
import { Button } from './Button';

const meta: Meta<typeof Button> = {
  title: 'UI/Button',
  component: Button,
  tags: ['autodocs'],
  argTypes: {
    variant: { control: 'select', options: ['primary', 'secondary'] },
    size: { control: 'radio', options: ['sm', 'md', 'lg'] },
  },
};
export default meta;

export const Primary: StoryObj<typeof Button> = {
  args: { variant: 'primary', children: '버튼' },
};

export const Loading: StoryObj<typeof Button> = {
  args: { isLoading: true, children: '로딩 중...' },
};
```

**핵심 기능:**
1. **독립 개발**: 앱과 분리된 환경에서 컴포넌트 개발
2. **시각적 테스트**: Chromatic으로 스크린샷 비교
3. **인터랙션 테스트**: play 함수로 사용자 시나리오 테스트
4. **자동 문서화**: autodocs로 Props 문서 자동 생성
5. **접근성 검사**: addon-a11y로 실시간 a11y 검사

**워크플로우:**
Storybook에서 컴포넌트 개발 → 시각적 리뷰(Chromatic) → 자동 문서화 → 디자인 시스템으로 배포
