Snapshot 테스트는 컴포넌트의 렌더링 결과를 파일로 저장하고, 이후 변경 여부를 확인합니다.

**기본 사용:**
```tsx
import { render } from '@testing-library/react';

test('Button 렌더링', () => {
  const { container } = render(<Button variant="primary">클릭</Button>);
  expect(container).toMatchSnapshot();
});

// 인라인 스냅샷
test('Button 텍스트', () => {
  const { getByRole } = render(<Button>클릭</Button>);
  expect(getByRole('button').textContent).toMatchInlineSnapshot(`"클릭"`);
});
```

**장점:**
- 설정이 간단하고 빠르게 작성 가능
- 의도치 않은 UI 변경 감지
- 대규모 리팩토링 시 안전망 역할

**단점:**
- 스냅샷이 너무 커지면 리뷰 불가능 ("승인 피로")
- 의미 있는 변경과 무의미한 변경 구분 어려움
- false positive 빈번 → 습관적으로 `--updateSnapshot` 실행

**올바른 사용법:**
1. 작은 단위로 스냅샷 (전체 페이지 X, 개별 컴포넌트 O)
2. 인라인 스냅샷 선호 (코드와 함께 리뷰 가능)
3. 동적 값(날짜, ID) 제외 처리
4. 행위 테스트(Testing Library)와 병행, 스냅샷만 의존하지 않기
5. 스냅샷 변경 시 PR에서 꼭 리뷰
