React Testing Library는 "구현이 아닌 동작"을 테스트하는 것을 핵심 원칙으로 합니다.

```typescript
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';

test('카운터 증가', async () => {
  render(<Counter />);

  // 사용자가 보는 것 기준으로 요소 선택
  const button = screen.getByRole('button', { name: '증가' });
  const count = screen.getByText('0');

  await userEvent.click(button);

  expect(screen.getByText('1')).toBeInTheDocument();
});
```

**쿼리 우선순위 (권장 순):**
1. `getByRole` - 접근성 역할
2. `getByLabelText` - 폼 요소
3. `getByPlaceholderText` - 입력 필드
4. `getByText` - 텍스트 콘텐츠
5. `getByTestId` - 최후의 수단

- 내부 state나 구현 세부사항을 테스트하지 않습니다.
- 사용자가 실제로 상호작용하는 방식으로 테스트를 작성합니다.
