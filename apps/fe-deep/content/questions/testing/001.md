테스트 피라미드에 따라 세 가지 주요 테스트 레벨이 있습니다.

| 레벨 | 대상 | 도구 | 속도 | 수량 |
|------|------|------|------|------|
| 단위(Unit) | 함수/컴포넌트 | Jest, Vitest | 빠름 | 많이 |
| 통합(Integration) | 여러 모듈 조합 | Testing Library | 보통 | 적당히 |
| E2E | 전체 시스템 | Playwright, Cypress | 느림 | 적게 |

```typescript
// 단위 테스트
test('add 함수', () => {
  expect(add(1, 2)).toBe(3);
});

// 통합 테스트 (React Testing Library)
test('폼 제출', async () => {
  render(<LoginForm />);
  await userEvent.type(screen.getByLabelText('이메일'), 'test@test.com');
  await userEvent.click(screen.getByRole('button', { name: '로그인' }));
  expect(screen.getByText('환영합니다')).toBeInTheDocument();
});

// E2E 테스트 (Playwright)
test('로그인 플로우', async ({ page }) => {
  await page.goto('/login');
  await page.fill('[name=email]', 'test@test.com');
  await page.click('button[type=submit]');
  await expect(page).toHaveURL('/dashboard');
});
```

- 단위 테스트를 가장 많이, E2E를 가장 적게 작성합니다.
- "사용자 관점"에서 테스트를 작성하는 것이 React Testing Library의 철학입니다.
