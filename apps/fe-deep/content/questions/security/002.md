CSRF는 인증된 사용자의 권한을 이용하여 의도하지 않은 요청을 보내는 공격입니다.

**공격 시나리오:**
1. 사용자가 은행 사이트에 로그인 (쿠키에 세션 저장)
2. 공격자의 사이트를 방문
3. 공격자 사이트에서 은행 API로 송금 요청 (쿠키가 자동 전송됨)

**방지 방법:**
- **CSRF 토큰**: 폼에 서버가 생성한 랜덤 토큰을 포함
- **SameSite 쿠키**: `SameSite=Strict` 또는 `Lax` 설정
- **Origin/Referer 헤더 검증**: 요청 출처 확인

```
Set-Cookie: session=abc123; SameSite=Lax; Secure; HttpOnly
```

- 현대 브라우저는 `SameSite=Lax`가 기본값이라 CSRF 위험이 줄었습니다.
- API 요청 시 Bearer 토큰(Authorization 헤더)을 사용하면 CSRF에 안전합니다.
