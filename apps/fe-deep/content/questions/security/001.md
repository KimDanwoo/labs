XSS는 공격자가 웹 페이지에 악성 스크립트를 삽입하여 사용자의 브라우저에서 실행시키는 공격입니다.

**종류:**
- **Stored XSS**: 서버에 악성 스크립트가 저장되어 다른 사용자에게 전달
- **Reflected XSS**: URL 파라미터를 통해 악성 스크립트가 반사
- **DOM-based XSS**: 클라이언트 측 JavaScript로 DOM을 조작하여 발생

**방지 방법:**
```javascript
// 1. 입력값 이스케이프
const escaped = input
  .replace(/&/g, '&amp;')
  .replace(/</g, '&lt;')
  .replace(/>/g, '&gt;');

// 2. React는 기본적으로 JSX를 이스케이프함 (안전)
<div>{userInput}</div> // 자동 이스케이프

// 3. dangerouslySetInnerHTML 사용 금지 (또는 DOMPurify로 sanitize)
import DOMPurify from 'dompurify';
<div dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(html) }} />

// 4. CSP 헤더 설정
// Content-Security-Policy: script-src 'self'
```

- React는 기본적으로 XSS를 방지하지만, `dangerouslySetInnerHTML` 사용 시 주의가 필요합니다.
- Content-Security-Policy(CSP) 헤더로 실행 가능한 스크립트를 제한할 수 있습니다.
