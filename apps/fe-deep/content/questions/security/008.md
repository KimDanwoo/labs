npm 생태계는 공급망 공격에 취약하므로 의존성 보안 관리가 필수입니다.

**자동화된 보안 검사:**
```bash
# npm 내장 감사
npm audit
npm audit fix

# Snyk (더 정밀한 분석)
npx snyk test

# GitHub Dependabot - 자동 PR 생성
# .github/dependabot.yml 설정
```

**보안 전략:**
1. **lock 파일 커밋**: `package-lock.json`으로 정확한 버전 고정
2. **정기적 npm audit**: CI/CD 파이프라인에 통합
3. **의존성 최소화**: 작은 유틸은 직접 구현 고려
4. **Dependabot/Renovate**: 자동 업데이트 PR
5. **License 검사**: `license-checker`로 라이센스 호환성 확인

**공급망 공격 방어:**
- SRI(Subresource Integrity)로 CDN 스크립트 무결성 검증
- `package.json`에서 버전 범위 제한 (`^` 대신 정확한 버전)
- npm provenance로 패키지 출처 검증
- socket.dev 등으로 의심스러운 패키지 탐지

**주의할 신호:**
- 갑작스러운 메인테이너 변경
- 설치 스크립트(`postinstall`) 포함 패키지
- 과도한 권한 요청 (네트워크, 파일시스템)
