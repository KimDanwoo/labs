쿠키의 보안 속성은 XSS, CSRF 등의 공격을 방어하는 핵심 메커니즘입니다.

```
Set-Cookie: session=abc123; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=86400
```

**HttpOnly:**
- JavaScript에서 `document.cookie`로 접근 불가
- XSS 공격으로 쿠키 탈취 방지
- 인증 토큰은 반드시 HttpOnly로 설정

**Secure:**
- HTTPS 연결에서만 쿠키 전송
- HTTP에서는 쿠키가 전송되지 않음
- 네트워크 도청(중간자 공격) 방지

**SameSite:**
- `Strict`: 외부 사이트에서의 요청에 쿠키 미포함 (CSRF 완전 차단)
- `Lax` (기본값): 외부 사이트에서 GET 링크 클릭 시에만 쿠키 포함
- `None`: 항상 포함 (반드시 Secure와 함께, 서드파티 쿠키)

**실무 설정 예시:**
```
# 인증 세션 쿠키
Set-Cookie: sid=xxx; HttpOnly; Secure; SameSite=Lax; Path=/

# CSRF 토큰 (JS 접근 필요)
Set-Cookie: csrf=yyy; Secure; SameSite=Strict; Path=/

# 서드파티 임베드용
Set-Cookie: embed=zzz; Secure; SameSite=None; Path=/
```

- 서드파티 쿠키는 점진적으로 차단 추세 (Privacy Sandbox)
