두 방식 모두 사용자 인증 상태를 관리하지만, 저장 위치와 동작이 다릅니다.

| 특성 | 세션 기반 | JWT |
|------|----------|-----|
| 상태 | 서버에 저장 (Stateful) | 토큰에 포함 (Stateless) |
| 저장 위치 | 서버 메모리/DB | 클라이언트 (쿠키/스토리지) |
| 확장성 | 서버 간 세션 공유 필요 | 토큰만 검증하면 됨 |
| 보안 | 서버에서 즉시 만료 가능 | 만료 전 강제 무효화 어려움 |

```javascript
// JWT 구조: Header.Payload.Signature
// eyJhbGciOiJIUzI1NiJ9.eyJ1c2VySWQiOjF9.signature

// JWT 사용
fetch('/api/data', {
  headers: { Authorization: 'Bearer ' + token }
});
```

- **세션**: 보안이 중요한 서비스 (은행 등)에 적합
- **JWT**: 마이크로서비스, 모바일 앱 등 스케일아웃이 필요한 환경에 적합
- Supabase는 JWT 기반 인증을 사용합니다.
