**수집 → 적재 → 처리 → 분석**

| 단계 | 설명 |
|------|------|
| **수집** | 다양한 소스에서 데이터 확보 |
| **적재** | 수집된 데이터를 저장소에 저장 |
| **처리** | 데이터 정제·변환·가공 |
| **분석** | 의미 있는 패턴·인사이트 도출 |

활용 목적: 비용 절감 / 문제 해결 / 트렌드 분석 / 의사결정 지원 / **미래 예측**
