**인공신경망 = 인간 뇌의 뉴런 구조를 모방한 모델**

| 계층 | 역할 |
|------|------|
| **입력층(Input)** | 외부 데이터를 받아들이는 첫 번째 층 |
| **은닉층(Hidden)** | 가중치 기반 계산·전달 (1개 이상) |
| **출력층(Output)** | 최종 예측값이나 분류 결과 산출 |

동작 원리:
- 각 뉴런은 입력에 **가중치(Weight)**를 곱하여 계산
- 결과를 다음 뉴런으로 **전달**
- 학습으로 가중치를 **조정**하여 성능 향상

딥러닝: 은닉층을 **여러 층** 쌓아 복잡한 패턴 학습
