**정의:** 첨단 컴퓨터·통신·측정 기술을 활용하여 자동으로 운행할 수 있는 **지능형 자동차**. 내·외부 상황을 실시간 인식하여 안전하고 편리한 **인간 중심 자동차**.

핵심 의미:
- 스마트 자동차 = **자동차 + IT + 통신 + 지능형 제어**의 융합
- 단순 이동수단이 아닌 **IT 기반 지능형 이동 공간**
- **제3의 생활공간**으로 발전 (집, 사무실에 이어)

주요 기술 동향: 연결성 / 안전성·편의성 향상 / 친환경 기술 / 자율주행 / 차량용 앱·앱스토어 / 자동차 OS
