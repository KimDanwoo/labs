| 구분 | IoT | USN |
|------|-----|-----|
| 범위 | 모든 사물의 인터넷 연결 | 센서 중심 네트워크 |
| 구성 | 사물+네트워크+데이터+서비스 | 센서 노드+싱크 노드+게이트웨이 |
| 사물 | 고정/이동/논리적 객체 | 주로 센서 디바이스 |
| 초점 | 인터넷 연결과 서비스 | 실시간 데이터 수집 |

**관계:**
USN은 **IoT를 구현하는 하위 기술**.
- IoT: "모든 사물의 인터넷 연결" → **상위 개념**
- USN: "센서 기반 데이터 수집 네트워크" → **구체적 구현**

USN이 수집한 데이터가 IoT 네트워크를 통해 서비스로 연결됩니다.
