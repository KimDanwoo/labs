유비쿼터스 기술 흐름에서 AI의 위치:
**센서 → 네트워크 → 데이터 → 처리 → 상황인식 → 지능형 서비스(AI)**

AI의 구체적 역할:
1. **상황 판단·추론** — 수집 데이터에서 사용자 상황을 지능적으로 파악
2. **패턴 인식** — 센서 데이터에서 의미 있는 패턴 발견
3. **예측·최적화** — 미래 상황 예측, 서비스 최적화
4. **자연어 이해** — HCI/HRI에서 사용자 의도 파악
5. **자율 제어** — 스마트카 자율주행, 스마트홈 자동 제어

AI는 수집된 데이터를 **의미 있는 지능형 서비스로 변환**하는 핵심 기술.
