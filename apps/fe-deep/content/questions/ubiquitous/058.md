**개인정보 침해 6유형 (순서 암기!):**

1. 개인정보의 부적절한 **접근·수집**
2. 개인정보의 부적절한 **분석**
3. 부적절한 **모니터링**
4. 부적절한 개인정보 **유통**
5. 원하지 않는 **영업행위** (스팸 등)
6. 부적절한 **저장**

암기 팁: **수집 → 분석 → 모니터링 → 유통 → 영업 → 저장**

데이터 생명주기와 비슷: 수집 → 분석 → 감시 → 퍼뜨림 → 활용 → 보관
