데이터 흐름 (반드시 암기):
센서 노드 → 싱크 노드 → 게이트웨이 → 외부 네트워크

구성요소:
• 센서 노드 — 환경 정보 수집, 데이터 생성, 인접 노드로 전달. 소형, 저전력, 다수 분산 배치.
• 싱크 노드 — 센서 노드 관리·제어, 데이터 수집·집계, 게이트웨이 기능, 외부 전달. 중앙 수집·중계 역할.
• 게이트웨이 — 센서 네트워크와 외부 네트워크(인터넷) 연결. 프로토콜 변환.

센서: 물리량·화학량·환경 정보를 감지하여 전기 신호로 변환하는 장치 (온도, 압력, 빛, 소리, 가속도 등)
