① 추상화(Abstraction) — 원시 데이터를 의미 있는 정보로 변환 (Raw→의미 데이터)
  예: GPS 좌표 → "서울 강남구 사무실"

② 해석(Interpretation) — 상황정보의 의미 분석
  예: "사무실에 있음" → "업무 중"으로 해석

③ 수집/집합(Aggregation) — 유사 상황정보를 통합
  예: 위치+시간+일정 → "회의 중"으로 통합

처리 순서: 원시 데이터 → 추상화 → 해석 → 집합 → 상황 판단

★ Aggregation = 유사 상황정보 "통합"이 핵심 키워드
