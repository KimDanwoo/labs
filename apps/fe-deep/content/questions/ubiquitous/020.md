블록 구조:
• 헤더(Header): 이전 블록 해시, 타임스탬프, 난이도, 넌스(Nonce) 등
• 몸체(Body): 실제 거래 데이터

블록 연결 원리:
각 블록은 이전 블록의 해시값을 헤더에 포함 → 체인 구조 유지
블록 A의 해시 → 블록 B 헤더에 저장 → 블록 B의 해시 → 블록 C 헤더에 저장...
★ 중간 블록 변조 시 이후 모든 블록의 해시가 변경되어 즉시 감지됨

블록 식별자:
• 블록 해시값 — 블록 헤더를 SHA-256으로 암호화하여 생성
• 블록 높이값 — 블록체인에서의 위치 정보
