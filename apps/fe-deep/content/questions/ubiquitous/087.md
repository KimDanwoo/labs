**X (틀림)**

SoC(System on Chip)는 단순 CPU가 아닌 **시스템 통합** 기술.

집적 요소: 메모리 / 디지털 회로 / 아날로그 회로 / CPU / 센서 / 안테나 / 수동소자

CPU는 SoC의 **구성요소 중 하나**일 뿐, SoC 자체가 CPU는 아닙니다.
