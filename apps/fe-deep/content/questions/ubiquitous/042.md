RFID(Radio Frequency Identification) 구성요소:

| 구성 | 역할 |
|------|------|
| **태그(Tag)** | 사물에 부착, 고유 정보 저장 |
| **리더(Reader)** | 태그 정보를 무선으로 읽음 |
| **미들웨어/서버** | 수집 데이터 처리·관리 |

RFID vs 바코드:
- **비접촉·원거리** 인식 가능
- 여러 태그 **동시 인식** 가능

RFID는 IoT의 핵심 기반 기술 중 하나입니다.
