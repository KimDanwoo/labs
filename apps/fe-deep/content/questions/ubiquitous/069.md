**인공지능**: 입력 데이터를 바탕으로 **컴퓨터가 스스로 학습**하여 규칙이나 알고리즘을 찾아냄

| 구분 | 기존 프로그래밍 | 인공지능 |
|------|---------------|----------|
| 방식 | 사람이 규칙을 직접 코딩 | 데이터로부터 규칙을 자동 학습 |
| 핵심 | 명시적 규칙 | **자동 학습** |
| 한계 | 규칙이 복잡해지면 한계 | 데이터가 많을수록 성능 향상 |
