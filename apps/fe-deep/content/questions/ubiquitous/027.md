IoT:
• 범위: 모든 사물의 인터넷 연결 (상위 개념)
• 구성: 사물 + 네트워크 + 데이터 + 서비스
• 사물: 고정/이동/논리적 객체 모두 포함
• 역할: USN을 포함하는 상위 개념

USN:
• 범위: 센서 중심 네트워크 (하위 구현 기술)
• 구성: 센서 노드 + 싱크 노드 + 게이트웨이
• 사물: 주로 센서 디바이스
• 역할: IoT의 하위 구현 기술 (데이터 수집 담당)

관계: USN은 IoT를 구현하는 센서 기반 수집 네트워크. IoT가 "연결"이라면 USN은 "수집".
