position 속성은 요소의 배치 방법을 결정합니다.

```css
/* static: 기본값, 문서 흐름에 따라 배치 */
.static { position: static; }

/* relative: 원래 위치 기준으로 이동 */
.relative { position: relative; top: 10px; left: 20px; }

/* absolute: 가장 가까운 positioned 조상 기준 */
.absolute { position: absolute; top: 0; right: 0; }

/* fixed: 뷰포트 기준으로 고정 */
.fixed { position: fixed; bottom: 20px; right: 20px; }

/* sticky: 스크롤 시 지정 위치에 고정 */
.sticky { position: sticky; top: 0; }
```

- **static**: 기본값. top/left 등의 오프셋이 적용되지 않습니다.
- **relative**: 자기 자신의 원래 위치를 기준으로 이동하며, 원래 공간은 유지됩니다.
- **absolute**: 문서 흐름에서 빠지며, positioned 조상(static이 아닌)을 기준으로 배치됩니다.
- **fixed**: 뷰포트 기준으로 고정되어 스크롤해도 위치가 변하지 않습니다.
- **sticky**: 스크롤 위치에 따라 relative와 fixed 사이를 전환합니다.
