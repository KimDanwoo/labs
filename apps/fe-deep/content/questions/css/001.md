Flexbox는 1차원 레이아웃 모델로, 주축(main axis)과 교차축(cross axis)을 기준으로 요소를 배치합니다.

```css
.container {
  display: flex;
  flex-direction: row;       /* 주축 방향: row | column */
  justify-content: center;   /* 주축 정렬 */
  align-items: center;       /* 교차축 정렬 */
  gap: 16px;                 /* 아이템 간격 */
  flex-wrap: wrap;           /* 줄바꿈 허용 */
}

.item {
  flex: 1;                   /* flex-grow: 1, flex-shrink: 1, flex-basis: 0 */
  flex-shrink: 0;            /* 축소 방지 */
}
```

- **justify-content**: 주축 방향 정렬 (flex-start, center, space-between, space-around, space-evenly)
- **align-items**: 교차축 정렬 (flex-start, center, stretch, baseline)
- **flex**: grow, shrink, basis를 한 번에 설정하는 축약 속성
- Grid와 달리 1차원(가로 또는 세로)으로만 레이아웃을 제어합니다.
