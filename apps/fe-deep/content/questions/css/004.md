모든 HTML 요소는 Box Model로 구성됩니다. 안쪽부터 content → padding → border → margin 순서입니다.

```css
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid black;
  margin: 10px;
}

/* 기본(content-box): 실제 너비 = 200 + 20*2 + 2*2 = 244px */
/* border-box: 실제 너비 = 200px (padding, border 포함) */

/* 전역으로 border-box 적용 (권장) */
*, *::before, *::after {
  box-sizing: border-box;
}
```

- **content-box** (기본값): width/height가 콘텐츠 영역만 지정합니다.
- **border-box**: width/height가 padding과 border를 포함합니다.
- 대부분의 프로젝트에서 `box-sizing: border-box`를 전역으로 설정하여 크기 계산을 직관적으로 만듭니다.
- margin은 box-sizing에 영향을 받지 않습니다.
