CSS Grid는 2차원 레이아웃, Flexbox는 1차원 레이아웃을 위한 모델입니다.

```css
/* Grid - 2차원: 행과 열을 동시에 제어 */
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto 1fr auto;
  gap: 16px;
}

/* Flexbox - 1차원: 행 또는 열 한 방향 */
.flex-container {
  display: flex;
  justify-content: space-between;
}
```

| 특성 | Grid | Flexbox |
|------|------|---------|
| 차원 | 2차원 (행+열) | 1차원 (행 또는 열) |
| 용도 | 전체 페이지 레이아웃 | 컴포넌트 내부 정렬 |
| 콘텐츠 vs 레이아웃 | 레이아웃 우선 | 콘텐츠 우선 |
| 아이템 배치 | 명시적 위치 지정 가능 | 순서 기반 |

- **Grid 사용**: 페이지 전체 레이아웃, 카드 그리드, 대시보드
- **Flexbox 사용**: 내비게이션 바, 버튼 그룹, 카드 내부 정렬
- 실무에서는 두 가지를 함께 사용하는 경우가 많습니다.
