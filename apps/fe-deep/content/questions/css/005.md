반응형 디자인은 다양한 화면 크기에 맞춰 레이아웃을 조정하는 웹 디자인 방식입니다.

```css
/* 1. Media Query */
@media (max-width: 768px) {
  .container { flex-direction: column; }
}

/* 2. 상대 단위 사용 */
.container {
  width: 90%;
  max-width: 1200px;
  font-size: clamp(14px, 2vw, 18px);
}

/* 3. 유동적 Grid */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
}

/* 4. 반응형 이미지 */
img {
  max-width: 100%;
  height: auto;
}
```

- **모바일 퍼스트**: 작은 화면부터 스타일링하고 `min-width` 미디어 쿼리로 확장하는 것이 권장됩니다.
- **상대 단위**: rem, em, %, vw, vh 등을 px 대신 사용합니다.
- **clamp()**: 최소값, 선호값, 최대값을 설정하여 유동적인 크기를 구현합니다.
- **Container Query**: 부모 요소의 크기에 따라 스타일을 변경하는 최신 기술도 있습니다.
