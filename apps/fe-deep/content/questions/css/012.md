**CSS-in-JS (styled-components, Emotion):**
```jsx
const Button = styled.button`
  background: ${props => props.primary ? '#3b82f6' : '#fff'};
  padding: 8px 16px;
`;
```
- 장점: 동적 스타일링, 스코프 격리, 컴포넌트와 스타일 공존
- 단점: 런타임 오버헤드, 번들 크기 증가, SSR 설정 복잡

**Utility-first CSS (Tailwind):**
```jsx
<button className="bg-blue-500 px-4 py-2 rounded hover:bg-blue-600">
```
- 장점: 런타임 비용 0, 작은 번들, 빠른 개발 속도
- 단점: 긴 className, HTML 가독성 저하

| 기준 | CSS-in-JS | Tailwind |
|------|-----------|----------|
| 런타임 비용 | 있음 | 없음 |
| 번들 크기 | 큼 | 작음 |
| 동적 스타일 | 강력 | 제한적 |
| SSR 호환 | 설정 필요 | 기본 호환 |

**트렌드**: Server Component 환경에서 CSS-in-JS의 런타임 한계로 Tailwind + CSS Modules 조합이 부상. Next.js 공식 권장: Tailwind CSS 또는 CSS Modules
