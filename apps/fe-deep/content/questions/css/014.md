논리적 속성은 물리적 방향(left/right) 대신 **콘텐츠 흐름 방향**에 따라 스타일을 적용합니다.

```css
/* 물리적 속성 */
.box { margin-left: 16px; padding-top: 8px; width: 200px; }

/* 논리적 속성 */
.box {
  margin-inline-start: 16px;  /* LTR→left, RTL→right */
  padding-block-start: 8px;
  inline-size: 200px;
}
```

| 물리적 | 논리적 |
|--------|--------|
| left/right | inline-start/end |
| top/bottom | block-start/end |
| width | inline-size |
| height | block-size |

**사용 이유:**
- 다국어 지원(i18n): RTL(아랍어, 히브리어) 자동 대응
- 세로 쓰기 모드 지원
- 미래 지향적 CSS 작성
- Tailwind CSS도 `ms-4`(margin-inline-start) 등 논리적 속성 유틸리티 제공
