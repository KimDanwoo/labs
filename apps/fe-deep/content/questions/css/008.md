Container Queries는 뷰포트가 아닌 **부모 컨테이너의 크기**를 기준으로 스타일을 적용합니다.

```css
.card-wrapper {
  container-type: inline-size;
  container-name: card;
}

@container card (min-width: 400px) {
  .card { display: grid; grid-template-columns: 200px 1fr; }
}
@container card (max-width: 399px) {
  .card { display: flex; flex-direction: column; }
}
```

| 기준 | Media Query | Container Query |
|------|-------------|------------------|
| 기준점 | 뷰포트 크기 | 부모 컨테이너 크기 |
| 재사용성 | 낮음 | 높음 |
| 컴포넌트 설계 | 어려움 | 자연스러움 |

**핵심**: 컴포넌트가 어디에 배치되든 자신의 크기에 맞게 반응 → 진정한 컴포넌트 기반 반응형 디자인
