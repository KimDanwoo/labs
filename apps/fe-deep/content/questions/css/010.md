`:has()`는 CSS의 **부모 선택자**로, 특정 자식/후속 요소를 포함하는 부모를 선택합니다.

```css
/* 이미지를 포함한 카드만 스타일 변경 */
.card:has(img) { grid-template-rows: auto 1fr; }

/* 체크된 체크박스의 부모 label */
label:has(input:checked) { background-color: #e0f0ff; }

/* 에러 필드가 있으면 제출 버튼 비활성화 스타일 */
form:has(.field-error) .submit-btn { opacity: 0.5; pointer-events: none; }

/* 비어있지 않은 입력 필드의 floating label */
.field:has(input:not(:placeholder-shown)) .label {
  transform: translateY(-20px);
  font-size: 12px;
}
```

**이전에는 불가능했던 것:**
- CSS만으로 부모 요소 선택
- 형제 요소 상태에 따른 스타일링
- JavaScript 없이 조건부 스타일링

`:has()`는 "CSS의 if문"이라 불릴 만큼 강력하며, 모든 모던 브라우저에서 지원됩니다.
