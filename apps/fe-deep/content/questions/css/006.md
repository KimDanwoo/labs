CSS 선택자 우선순위는 여러 규칙이 같은 요소에 적용될 때 어떤 스타일이 우선하는지 결정합니다.

**우선순위 계산 (높은 순):**

1. `!important` — 최우선 (사용 자제)
2. 인라인 스타일 — `style="..."` (1,0,0,0)
3. ID 선택자 — `#id` (0,1,0,0)
4. 클래스/속성/가상클래스 — `.class`, `[attr]`, `:hover` (0,0,1,0)
5. 태그/가상요소 — `div`, `::before` (0,0,0,1)
6. 전체 선택자 — `*` (0,0,0,0)

```css
/* 우선순위: 0,1,1,1 */
#header .nav a { color: blue; }

/* 우선순위: 0,0,2,1 */
.nav .link a { color: red; }

/* #header가 포함되어 있으므로 첫 번째 규칙이 적용됨 */
```

- 우선순위가 같으면 나중에 선언된 스타일이 적용됩니다.
- `!important`는 디버깅을 어렵게 만들므로 가능한 사용하지 않습니다.
- BEM이나 Tailwind CSS를 사용하면 우선순위 충돌을 줄일 수 있습니다.
