JavaScript에서 배열과 객체의 주요 연산 시간 복잡도입니다.

**배열:**
- 인덱스 접근: O(1)
- push/pop (끝): O(1)
- shift/unshift (앞): O(n)
- includes/indexOf: O(n)
- splice: O(n)

**객체 (해시맵):**
- 속성 접근: O(1) 평균
- 속성 추가/삭제: O(1) 평균
- Object.keys(): O(n)

```javascript
// Map vs Object
const map = new Map();
map.set('key', 'value'); // O(1)
map.get('key');           // O(1)
map.has('key');           // O(1)
map.size;                 // O(1) - Object는 Object.keys().length로 O(n)

// Set - 중복 없는 값의 집합
const set = new Set([1, 2, 3, 3]);
set.has(2);  // O(1) - 배열의 includes()는 O(n)
```

- 빠른 조회가 필요하면 Map/Set을 사용합니다.
- 순서가 중요하면 배열, 키-값 매핑이면 객체/Map을 사용합니다.
