스택은 LIFO(Last In First Out), 큐는 FIFO(First In First Out) 구조입니다.

```javascript
// 스택 - 배열로 구현
class Stack {
  #items = [];
  push(item) { this.#items.push(item); }
  pop() { return this.#items.pop(); }
  peek() { return this.#items[this.#items.length - 1]; }
  isEmpty() { return this.#items.length === 0; }
}

// 큐 - 객체로 효율적 구현 (shift는 O(n)이므로)
class Queue {
  #items = {};
  #head = 0;
  #tail = 0;
  enqueue(item) { this.#items[this.#tail++] = item; }
  dequeue() {
    if (this.isEmpty()) return undefined;
    const item = this.#items[this.#head];
    delete this.#items[this.#head++];
    return item;
  }
  isEmpty() { return this.#head === this.#tail; }
}
```

**프론트엔드 활용:**
- 스택: 브라우저 히스토리(뒤로가기), Undo/Redo, 함수 호출 스택
- 큐: 이벤트 큐, 비동기 작업 큐, 메시지 큐
