그래프는 노드(정점)와 엣지(간선)로 이루어진 비선형 자료구조입니다.

**JavaScript 구현:**
```javascript
// 인접 리스트 방식
class Graph {
  constructor() { this.adjacencyList = new Map(); }

  addVertex(v) { this.adjacencyList.set(v, []); }
  addEdge(v1, v2) {
    this.adjacencyList.get(v1).push(v2);
    this.adjacencyList.get(v2).push(v1); // 무방향
  }

  bfs(start) {
    const visited = new Set([start]);
    const queue = [start];
    while (queue.length) {
      const vertex = queue.shift();
      for (const neighbor of this.adjacencyList.get(vertex)) {
        if (!visited.has(neighbor)) {
          visited.add(neighbor);
          queue.push(neighbor);
        }
      }
    }
    return visited;
  }
}
```

**프론트엔드 활용:**
1. **모듈 의존성 그래프**: Webpack/Rollup의 번들링 기초
2. **라우팅**: 페이지 간 이동 경로 탐색
3. **컴포넌트 트리**: React 컴포넌트 의존성 분석
4. **소셜 네트워크**: 친구 관계 시각화
5. **상태 머신**: XState 등에서 상태 전이 그래프

| 표현 방식 | 장점 | 단점 |
|----------|------|------|
| 인접 행렬 | 간선 확인 O(1) | 메모리 O(V²) |
| 인접 리스트 | 메모리 효율적 | 간선 확인 O(V) |
