Trie는 문자열 검색에 특화된 트리 자료구조로, **접두사(prefix) 검색에 최적화**되어 있습니다.

```javascript
class TrieNode {
  constructor() {
    this.children = new Map();
    this.isEnd = false;
  }
}

class Trie {
  constructor() { this.root = new TrieNode(); }

  insert(word) {
    let node = this.root;
    for (const char of word) {
      if (!node.children.has(char)) {
        node.children.set(char, new TrieNode());
      }
      node = node.children.get(char);
    }
    node.isEnd = true;
  }

  // 자동완성: 접두사로 시작하는 모든 단어 반환
  autocomplete(prefix, limit = 10) {
    let node = this.root;
    for (const char of prefix) {
      if (!node.children.has(char)) return [];
      node = node.children.get(char);
    }
    const results = [];
    this._dfs(node, prefix, results, limit);
    return results;
  }

  _dfs(node, prefix, results, limit) {
    if (results.length >= limit) return;
    if (node.isEnd) results.push(prefix);
    for (const [char, child] of node.children) {
      this._dfs(child, prefix + char, results, limit);
    }
  }
}
```

**프론트엔드 활용:**
- 검색 자동완성 (Trie + debounce)
- 사전/맞춤법 검사
- IP 라우팅 테이블
- 태그/해시태그 추천

**시간 복잡도:** 삽입/검색 O(L), L = 문자열 길이
- 일반 배열 필터링 O(N*L) vs Trie O(L) → 대용량 데이터에서 압도적 우위
