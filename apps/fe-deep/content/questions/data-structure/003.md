DOM(Document Object Model)은 트리 자료구조로 HTML 문서를 표현합니다.

```javascript
// DOM 트리 순회 - BFS (너비 우선)
function traverseBFS(root) {
  const queue = [root];
  while (queue.length > 0) {
    const node = queue.shift();
    console.log(node.tagName);
    queue.push(...node.children);
  }
}

// DOM 트리 순회 - DFS (깊이 우선)
function traverseDFS(node) {
  console.log(node.tagName);
  for (const child of node.children) {
    traverseDFS(child);
  }
}

// React의 Virtual DOM도 트리 구조
// Reconciliation은 두 트리의 diff를 계산하는 알고리즘
```

- DOM은 부모-자식 관계의 트리 구조입니다.
- React의 Reconciliation은 O(n) 복잡도로 트리 비교를 수행합니다.
- 같은 레벨의 같은 타입 요소만 비교하여 효율을 높입니다.
