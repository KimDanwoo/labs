iframe은 외부 콘텐츠를 임베드하지만 보안 위험이 있습니다.

**보안 위험:**
- 클릭재킹(Clickjacking): 투명 iframe으로 사용자 클릭 가로채기
- 악성 스크립트 실행: 외부 페이지의 JS가 부모 페이지에 영향
- 피싱: 신뢰할 수 없는 콘텐츠 표시

**sandbox 속성:**
```html
<iframe src="https://external.com" sandbox="allow-scripts allow-same-origin">
</iframe>
```
- `sandbox` (값 없이): 모든 기능 차단
- `allow-scripts`: JS 실행 허용
- `allow-same-origin`: 동일 출처 정책 유지
- `allow-forms`: 폼 제출 허용
- `allow-popups`: 팝업 허용

**추가 방어:**
- `X-Frame-Options: DENY` 헤더로 자신의 페이지가 iframe에 로드되는 것 방지
- CSP의 `frame-ancestors` 디렉티브 사용
- `referrerPolicy`와 `loading="lazy"` 활용
