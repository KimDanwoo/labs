HTML 요소는 크게 블록(block) 레벨과 인라인(inline) 레벨로 나뉩니다.

**Block 요소:**
- 항상 새로운 줄에서 시작하며 가능한 최대 너비를 차지합니다.
- width, height, margin, padding을 모두 설정할 수 있습니다.
- 예: `<div>`, `<p>`, `<h1>`~`<h6>`, `<section>`, `<article>`

**Inline 요소:**
- 줄바꿈 없이 콘텐츠 흐름 내에 배치됩니다.
- width, height 설정이 불가능하며, 상하 margin은 적용되지 않습니다.
- 예: `<span>`, `<a>`, `<strong>`, `<em>`, `<img>`

```css
/* inline 요소를 block처럼 사용하려면 */
span { display: block; }
/* 또는 둘의 특성을 합친 */
span { display: inline-block; }
```

**대체 인라인 요소 (Replaced Inline Element)**
`<img>`, `<input>`, `<video>` 등은 인라인 요소이지만 예외적으로 `width`·`height` 설정이 가능합니다. 외부 콘텐츠(이미지, 미디어)로 대체(replace)되는 특성 때문에 일반 인라인 요소와 달리 박스 크기를 가집니다.
