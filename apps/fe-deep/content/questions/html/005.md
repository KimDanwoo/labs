meta 태그는 HTML 문서의 메타데이터(문서에 대한 정보)를 정의합니다. `<head>` 안에 위치하며 브라우저, 검색 엔진, SNS 등에 정보를 제공합니다.

```html
<!-- 문자 인코딩 -->
<meta charset="UTF-8">

<!-- 반응형 뷰포트 -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<!-- SEO -->
<meta name="description" content="페이지 설명">
<meta name="keywords" content="키워드1, 키워드2">

<!-- OG(Open Graph) - SNS 공유 시 -->
<meta property="og:title" content="페이지 제목">
<meta property="og:description" content="설명">
<meta property="og:image" content="이미지 URL">
```

- **charset**: 문서의 문자 인코딩을 지정합니다.
- **viewport**: 모바일 반응형 디자인에 필수적인 뷰포트 설정입니다.
- **description**: 검색 결과에 표시되는 페이지 설명으로 SEO에 중요합니다.
