검색 엔진 최적화를 위한 HTML 마크업 전략입니다.

**필수 메타 태그:**
```html
<head>
  <title>페이지 제목 (60자 이내)</title>
  <meta name="description" content="페이지 설명 (160자 이내)">
  <link rel="canonical" href="https://example.com/page">
</head>
```

**시맨틱 구조:**
- `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>` 활용
- `<h1>`은 페이지당 1개, heading 계층 순서 준수
- `<img alt="설명">` 모든 이미지에 대체 텍스트

**구조화된 데이터 (JSON-LD):**
```html
<script type="application/ld+json">
{ "@context": "https://schema.org", "@type": "Article", "headline": "제목" }
</script>
```

**Open Graph & Twitter Card:**
```html
<meta property="og:title" content="제목">
<meta property="og:image" content="https://example.com/image.jpg">
```

- `robots.txt`, `sitemap.xml` 관리
- Core Web Vitals 최적화가 SEO 순위에 직접 영향
