WAI-ARIA는 시맨틱 HTML만으로 표현할 수 없는 접근성 정보를 보완합니다.

**Role (역할):**
```html
<div role="tablist">
  <button role="tab" aria-selected="true">탭 1</button>
  <button role="tab" aria-selected="false">탭 2</button>
</div>
<div role="tabpanel">탭 내용</div>
```

**State (상태 — 동적 변경):**
- `aria-expanded`: 접힘/펼침
- `aria-selected`: 선택 상태
- `aria-disabled`: 비활성화
- `aria-hidden`: 스크린 리더에서 숨김

**Property (속성 — 비교적 고정):**
- `aria-label`: 요소의 레이블
- `aria-labelledby`: 다른 요소로 레이블 참조
- `aria-describedby`: 추가 설명 참조
- `aria-live="polite/assertive"`: 동적 콘텐츠 변경 알림

**핵심 원칙:**
1. 네이티브 HTML 요소를 우선 사용 (button > div[role=button])
2. 키보드 접근성 보장 (tabindex, focus 관리)
3. ARIA는 보조 수단이지 대체 수단이 아님
