웹 접근성은 장애가 있는 사용자를 포함한 모든 사람이 웹 콘텐츠를 이용할 수 있도록 하는 것입니다. WCAG(Web Content Accessibility Guidelines)가 국제 표준입니다.

**주요 개선 방법:**

```html
<!-- 1. 이미지에 대체 텍스트 -->
<img src="logo.png" alt="회사 로고">

<!-- 2. 폼 요소에 label 연결 -->
<label for="email">이메일</label>
<input type="email" id="email">

<!-- 3. ARIA 속성 활용 -->
<button aria-label="메뉴 닫기" aria-expanded="false">
  <svg>...</svg>
</button>

<!-- 4. 키보드 내비게이션 보장 -->
<div role="button" tabindex="0" onkeydown="handleKey(event)">
  클릭 가능한 요소
</div>
```

- 시맨틱 HTML 사용이 접근성의 기본입니다.
- 색상 대비(contrast ratio)를 4.5:1 이상으로 유지해야 합니다.
- 키보드만으로 모든 기능을 사용할 수 있어야 합니다.
- 스크린 리더 테스트를 통해 접근성을 검증합니다.
