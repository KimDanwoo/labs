Web Components는 재사용 가능한 커스텀 HTML 요소를 만들기 위한 웹 표준 기술의 모음입니다.

**3가지 핵심 기술:**

1. **Custom Elements**: 새로운 HTML 태그를 정의
2. **Shadow DOM**: 캡슐화된 DOM 트리를 생성
3. **HTML Templates**: 재사용 가능한 마크업 템플릿

```javascript
class MyCard extends HTMLElement {
  constructor() {
    super();
    // Shadow DOM 생성
    const shadow = this.attachShadow({ mode: 'open' });
    shadow.innerHTML = \`
      <style>
        .card { padding: 16px; border: 1px solid #ccc; border-radius: 8px; }
      </style>
      <div class="card">
        <slot></slot>
      </div>
    \`;
  }
}

customElements.define('my-card', MyCard);
```

```html
<my-card>이것은 커스텀 카드입니다</my-card>
```

- Shadow DOM을 통해 스타일이 외부와 격리되어 CSS 충돌이 없습니다.
- 프레임워크에 의존하지 않는 네이티브 컴포넌트를 만들 수 있습니다.
- React, Vue 등과 함께 사용할 수도 있습니다.
