세 가지 모두 클라이언트 측 데이터 저장 방식이지만, 용도와 특성이 다릅니다.

| 특성 | Cookie | localStorage | sessionStorage |
|------|--------|-------------|----------------|
| 용량 | ~4KB | ~5-10MB | ~5-10MB |
| 만료 | 설정 가능 | 영구 | 탭/창 닫으면 삭제 |
| 서버 전송 | 매 요청마다 | X | X |
| 범위 | 도메인 전체 | 도메인 전체 | 탭/창별 |

```javascript
// Cookie
document.cookie = "name=value; expires=Fri, 31 Dec 2027 23:59:59 GMT; path=/";

// localStorage
localStorage.setItem('key', 'value');
const value = localStorage.getItem('key');

// sessionStorage
sessionStorage.setItem('key', 'value');
```

- **Cookie**: 서버와의 통신이 필요한 인증 토큰 등에 사용
- **localStorage**: 사용자 설정, 테마 등 영구적 데이터에 사용
- **sessionStorage**: 임시 폼 데이터 등 세션 한정 데이터에 사용
