시맨틱 HTML은 태그 이름만으로 콘텐츠의 의미와 구조를 전달하는 마크업 방식입니다.

```html
<!-- 비시맨틱 -->
<div class="header">...</div>
<div class="nav">...</div>

<!-- 시맨틱 -->
<header>...</header>
<nav>...</nav>
<main>...</main>
<article>...</article>
<footer>...</footer>
```

- **접근성(Accessibility)**: 스크린 리더가 페이지 구조를 올바르게 해석할 수 있습니다.
- **SEO**: 검색 엔진이 콘텐츠의 중요도와 관계를 더 잘 이해합니다.
- **유지보수성**: 코드만 보고도 페이지 구조를 파악할 수 있어 협업이 용이합니다.
- 주요 시맨틱 태그: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`
