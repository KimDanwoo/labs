둘 다 그래픽을 표현하지만 방식이 근본적으로 다릅니다.

**SVG:** XML 기반 벡터 그래픽. DOM 요소로 존재하여 CSS 스타일링과 이벤트 핸들링 가능. 확대해도 품질 유지. 요소가 많아지면 DOM 부담.

**Canvas:** JavaScript로 픽셀 단위 렌더링. DOM에 단일 요소만 존재. 개별 요소에 이벤트 바인딩 불가. 수만 개 객체도 빠르게 렌더링.

| 기준 | SVG | Canvas |
|------|-----|--------|
| 그래픽 방식 | 벡터 | 래스터 |
| DOM 접근 | O | X |
| 이벤트 핸들링 | 쉬움 | 직접 구현 |
| 성능 (많은 요소) | 느림 | 빠름 |
| 해상도 독립 | O | X |
| 접근성 | 좋음 | 나쁨 |

**사용 시점:**
- SVG: 아이콘, 로고, 차트(D3.js), 인터랙티브 UI
- Canvas: 게임, 이미지 편집, 대용량 데이터 시각화, 애니메이션
