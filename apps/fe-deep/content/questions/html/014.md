브라우저 네이티브 지연 로딩으로 초기 로딩 성능을 개선합니다.

```html
<img src="photo.jpg" loading="lazy" alt="사진" width="400" height="300">
<iframe src="https://youtube.com/embed/..." loading="lazy"></iframe>
<img src="hero.jpg" loading="eager" alt="히어로 이미지">
```

**loading 속성 값:**
- `lazy`: 뷰포트 근처에 도달할 때 로드
- `eager`: 즉시 로드 (기본값)

**주의사항:**
- LCP 요소에는 사용 금지 → `loading="eager"` 또는 속성 생략
- `width`, `height` 속성을 반드시 명시 → CLS 방지
- Above-the-fold(첫 화면) 이미지에는 사용하지 않음
- Next.js `<Image>` 컴포넌트는 기본적으로 lazy loading 적용
