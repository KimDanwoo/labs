Web Worker는 메인 스레드와 별도로 **백그라운드 스레드에서 JavaScript를 실행**합니다.

**기본 사용:**
```javascript
// worker.js
self.onmessage = (e) => {
  const result = heavyComputation(e.data);
  self.postMessage(result);
};

// main.js
const worker = new Worker('worker.js');
worker.postMessage(largeData);
worker.onmessage = (e) => updateUI(e.data);
```

**React에서 활용 (Comlink):**
```javascript
// worker.ts
import { expose } from 'comlink';
const api = {
  sortData: (data) => data.sort((a, b) => a.score - b.score),
  parseCSV: (csv) => { /* 파싱 로직 */ },
};
expose(api);

// useWorker.ts
import { wrap } from 'comlink';
const worker = wrap(new Worker(new URL('./worker.ts', import.meta.url)));
const sorted = await worker.sortData(hugeArray);
```

**적합한 작업:**
- 대용량 데이터 정렬/필터링 (10,000+ 행)
- CSV/JSON 파싱
- 이미지 프로세싱 (리사이즈, 필터)
- 암호화/해싱
- 복잡한 정규식 매칭

**한계:**
- DOM 접근 불가
- postMessage로만 통신 (Transferable 객체로 성능 개선 가능)
- Worker 생성 비용 있음 → 재사용 권장

**판단 기준:** 작업이 50ms 이상 걸려 프레임 드랍이 발생한다면 Worker 고려
