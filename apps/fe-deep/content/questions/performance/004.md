둘 다 이벤트 발생 빈도를 제어하는 기법이지만, 동작 방식이 다릅니다.

**Debounce**: 마지막 호출 후 일정 시간이 지나면 실행 (검색 입력에 적합)

**Throttle**: 일정 시간 간격으로 최대 1회 실행 (스크롤 이벤트에 적합)

```javascript
// Debounce 구현
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

// Throttle 구현
function throttle(fn, limit) {
  let inThrottle = false;
  return (...args) => {
    if (!inThrottle) {
      fn(...args);
      inThrottle = true;
      setTimeout(() => inThrottle = false, limit);
    }
  };
}

// 사용 예
const search = debounce((query) => fetchResults(query), 300);
const onScroll = throttle(() => checkPosition(), 100);
```

- **Debounce**: 검색 입력, 창 리사이즈, 자동 저장
- **Throttle**: 스크롤 이벤트, 마우스 이동, API rate limiting
