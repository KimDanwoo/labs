코드 스플리팅은 번들을 여러 청크로 나누어 필요할 때만 로드하는 기법입니다.

```typescript
// React.lazy + Suspense
import { lazy, Suspense } from 'react';

const HeavyComponent = lazy(() => import('./HeavyComponent'));

function App() {
  return (
    <Suspense fallback={<div>로딩 중...</div>}>
      <HeavyComponent />
    </Suspense>
  );
}

// Next.js dynamic import
import dynamic from 'next/dynamic';

const Chart = dynamic(() => import('./Chart'), {
  loading: () => <p>차트 로딩 중...</p>,
  ssr: false, // 클라이언트에서만 렌더링
});
```

- 초기 번들 크기를 줄여 첫 로드 시간을 단축합니다.
- 라우트 기반 스플리팅이 가장 효과적입니다.
- Next.js App Router는 기본적으로 라우트별 코드 스플리팅을 수행합니다.
