메모리 누수는 더 이상 필요 없는 메모리가 해제되지 않아 점진적으로 메모리가 증가하는 현상입니다.

**주요 원인:**
1. **해제 안 된 이벤트 리스너**: addEventListener 후 removeEventListener 누락
2. **해제 안 된 타이머**: setInterval/setTimeout 후 clear 누락
3. **클로저 참조**: 콜백이 큰 객체를 참조하여 GC 방지
4. **분리된 DOM**: DOM에서 제거했지만 JS 변수가 참조 유지
5. **전역 변수 누적**: window 객체에 계속 데이터 추가

**React에서의 누수:**
```javascript
// BAD: cleanup 없는 useEffect
useEffect(() => {
  const ws = new WebSocket('ws://...');
  ws.onmessage = (e) => setData(JSON.parse(e.data));
  // WebSocket이 닫히지 않음!
}, []);

// GOOD: cleanup 포함
useEffect(() => {
  const ws = new WebSocket('ws://...');
  ws.onmessage = (e) => setData(JSON.parse(e.data));
  return () => ws.close(); // cleanup
}, []);
```

**디버깅 방법:**
1. Chrome DevTools → Memory 탭 → Heap Snapshot 3회 촬영 비교
2. Allocation Timeline으로 메모리 할당 추적
3. Performance Monitor에서 JS Heap 그래프 관찰
4. `performance.measureUserAgentSpecificMemory()` API

**핵심:** useEffect cleanup, AbortController, WeakRef/WeakMap 활용
