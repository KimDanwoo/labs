이미지는 웹 페이지에서 가장 큰 용량을 차지하므로 최적화가 중요합니다.

```html
<!-- 반응형 이미지 -->
<img
  srcset="image-300.jpg 300w, image-600.jpg 600w, image-1200.jpg 1200w"
  sizes="(max-width: 600px) 300px, (max-width: 1200px) 600px, 1200px"
  src="image-600.jpg"
  alt="설명"
  loading="lazy"
  decoding="async"
/>
```

**최적화 방법:**
- **포맷**: WebP, AVIF 사용 (JPEG 대비 25-50% 작음)
- **레이지 로딩**: `loading="lazy"`로 뷰포트 밖 이미지 지연 로드
- **사이즈 지정**: width, height를 명시하여 CLS 방지
- **CDN**: 이미지 CDN으로 자동 리사이즈/포맷 변환
- **Next.js Image**: `next/image`가 자동으로 최적화 처리

Next.js의 `<Image>` 컴포넌트는 자동 WebP 변환, 레이지 로딩, 반응형 크기 조절을 제공합니다.
