INP는 FID를 대체한 Core Web Vitals 지표로, **사용자 상호작용 후 화면 업데이트까지의 지연 시간**을 측정합니다.

**측정 기준:**
- 클릭, 탭, 키보드 입력 등 모든 상호작용의 지연 시간 중 가장 느린 값
- 좋음: 200ms 이하 / 개선 필요: 200~500ms / 나쁨: 500ms 초과

**INP가 느려지는 원인:**
1. 메인 스레드를 오래 점유하는 JavaScript 실행
2. 큰 컴포넌트 리렌더링
3. 레이아웃 스래싱 (강제 동기 레이아웃)
4. 서드파티 스크립트 간섭

**개선 전략:**
```javascript
// 1. 긴 작업 분리 (yield to main thread)
function yieldToMain() {
  return new Promise(resolve => setTimeout(resolve, 0));
}
async function processItems(items) {
  for (const item of items) {
    processItem(item);
    if (items.indexOf(item) % 5 === 0) await yieldToMain();
  }
}

// 2. React useTransition으로 비긴급 업데이트 분리
const [isPending, startTransition] = useTransition();
startTransition(() => setFilteredList(heavyFilter(list)));

// 3. Web Worker로 CPU 집약 작업 오프로드
```

- `isInputPending()` API로 대기 중인 입력 확인 가능
- Chrome DevTools Performance 탭에서 Long Tasks 식별
