프론트엔드 면접에서 자주 다루는 정렬 알고리즘입니다.

| 알고리즘 | 평균 | 최악 | 공간 | 안정성 |
|----------|------|------|------|--------|
| 버블 정렬 | O(n²) | O(n²) | O(1) | 안정 |
| 삽입 정렬 | O(n²) | O(n²) | O(1) | 안정 |
| 퀵 정렬 | O(n log n) | O(n²) | O(log n) | 불안정 |
| 병합 정렬 | O(n log n) | O(n log n) | O(n) | 안정 |

```javascript
// JavaScript의 Array.sort()
// V8 엔진: TimSort (병합 + 삽입 정렬 하이브리드) - O(n log n)
const nums = [3, 1, 4, 1, 5];
nums.sort((a, b) => a - b); // 오름차순

// 객체 배열 정렬
users.sort((a, b) => a.name.localeCompare(b.name));
```

- JavaScript의 `Array.sort()`는 비교 함수 없이 호출하면 문자열로 변환 후 정렬합니다.
- 반드시 비교 함수를 전달해야 숫자도 올바르게 정렬됩니다.
