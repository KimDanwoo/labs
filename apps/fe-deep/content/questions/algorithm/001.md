Big O 표기법은 알고리즘의 성능을 입력 크기(n)에 대한 함수로 표현합니다.

**주요 시간 복잡도 (빠른 순):**
- O(1): 상수 시간 (해시 조회)
- O(log n): 로그 시간 (이진 탐색)
- O(n): 선형 시간 (배열 순회)
- O(n log n): (정렬 알고리즘)
- O(n²): (이중 루프)
- O(2ⁿ): 지수 시간 (재귀 피보나치)

```javascript
// O(1) - 상수 시간
arr[0]; // 인덱스 접근

// O(n) - 선형 시간
arr.find(x => x === target);

// O(n²) - 이차 시간
for (let i = 0; i < n; i++)
  for (let j = 0; j < n; j++)
    // ...

// O(log n) - 로그 시간 (이진 탐색)
function binarySearch(arr, target) {
  let left = 0, right = arr.length - 1;
  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
```

- 최악의 경우를 기준으로 분석하는 것이 일반적입니다.
- 프론트엔드에서는 대부분 O(n) 또는 O(n log n) 이하의 알고리즘을 사용합니다.
