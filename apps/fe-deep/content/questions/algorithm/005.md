슬라이딩 윈도우는 배열/문자열에서 **연속된 부분 집합**을 효율적으로 탐색하는 기법입니다.

**고정 크기 윈도우:**
```javascript
// 크기 k인 연속 부분 배열의 최대 합
function maxSubarraySum(arr, k) {
  let windowSum = arr.slice(0, k).reduce((a, b) => a + b);
  let maxSum = windowSum;

  for (let i = k; i < arr.length; i++) {
    windowSum += arr[i] - arr[i - k]; // O(1)로 윈도우 이동
    maxSum = Math.max(maxSum, windowSum);
  }
  return maxSum;
}
```

**가변 크기 윈도우:**
```javascript
// 합이 target 이상인 최소 길이 부분 배열
function minSubarrayLen(arr, target) {
  let left = 0, sum = 0, minLen = Infinity;

  for (let right = 0; right < arr.length; right++) {
    sum += arr[right];
    while (sum >= target) {
      minLen = Math.min(minLen, right - left + 1);
      sum -= arr[left++];
    }
  }
  return minLen === Infinity ? 0 : minLen;
}
```

**프론트엔드 활용:**
- 가상 스크롤: 보이는 영역(윈도우)의 아이템만 렌더링
- 최근 N개 이벤트 추적 (성능 모니터링)
- 문자열 검색: 중복 없는 최장 부분 문자열

**핵심:** O(n²)를 O(n)으로 최적화하는 패턴
