캐시 메모리는 CPU와 메인 메모리 사이에서 **자주 사용되는 데이터를 빠르게 제공**하는 소형 고속 메모리입니다.

**캐시 계층:**
- L1 캐시: 가장 빠름, 가장 작음 (32~64KB), CPU 코어별
- L2 캐시: 중간 (256KB~1MB), CPU 코어별
- L3 캐시: 가장 큼 (수 MB~수십 MB), 코어 공유

**캐시 동작 원리:**
- **Temporal Locality**: 최근 접근한 데이터는 다시 접근될 가능성 높음
- **Spatial Locality**: 인접한 메모리 주소의 데이터도 함께 캐시

**프론트엔드 캐싱과의 공통 원리:**

| CPU 캐시 | 프론트엔드 캐시 |
|----------|----------------|
| L1/L2/L3 계층 | 메모리 > 디스크 > CDN > 서버 |
| Cache Hit/Miss | Cache-Control hit/miss |
| LRU 교체 정책 | LRU 기반 캐시 무효화 |
| Temporal Locality | stale-while-revalidate |
| Spatial Locality | 프리페칭 (prefetch) |

**코드 레벨 캐시 최적화:**
```javascript
// 배열 순차 접근 (cache-friendly)
for (let i = 0; i < arr.length; i++) sum += arr[i]; // 좋음
// 랜덤 접근 (cache-unfriendly)
for (const idx of randomIndices) sum += arr[idx]; // 나쁨
```

동일한 캐시 원리가 CPU~CDN~브라우저까지 모든 계층에 적용됩니다.
