네트워크 통신을 계층적으로 분류한 모델입니다.

**OSI 7계층 → TCP/IP 4계층 매핑:**
```
OSI 7계층          TCP/IP 4계층
─────────         ────────────
7. 응용 (HTTP)  ┐
6. 표현        ├→ 응용 (Application)
5. 세션        ┘
4. 전송 (TCP)  →  전송 (Transport)
3. 네트워크 (IP)→  인터넷 (Internet)
2. 데이터링크  ┐
1. 물리        ┘→  네트워크 접근
```

**프론트엔드 관련 계층:**
- **응용 계층**: HTTP/HTTPS, WebSocket, DNS
- **전송 계층**: TCP(안정적), UDP(빠름)
- **인터넷 계층**: IP 주소, 라우팅

- 프론트엔드 개발자는 주로 응용 계층(HTTP)을 다룹니다.
- TCP의 3-way handshake, HTTP/2의 멀티플렉싱 등이 자주 출제됩니다.
