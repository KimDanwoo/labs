가비지 컬렉션(GC)은 사용되지 않는 메모리를 자동으로 해제하는 메커니즘입니다.

**JavaScript의 GC 알고리즘:**

1. **참조 카운팅**: 참조 수가 0이면 해제 (순환 참조 문제)
2. **Mark-and-Sweep** (현재 사용): 루트에서 도달 불가능한 객체를 해제

```javascript
// 메모리 누수 사례
// 1. 해제되지 않는 이벤트 리스너
element.addEventListener('click', handler);
// element가 제거되어도 handler가 참조 유지 → 메모리 누수

// 2. 클로저에 의한 참조 유지
function createLeak() {
  const largeData = new Array(1000000);
  return () => console.log(largeData.length);
  // largeData가 클로저에 의해 유지됨
}

// 3. React에서의 메모리 누수 방지
useEffect(() => {
  const controller = new AbortController();
  fetch(url, { signal: controller.signal });
  return () => controller.abort(); // 클린업
}, [url]);
```

- React의 useEffect 클린업 함수로 이벤트 리스너, 타이머, 구독을 정리해야 합니다.
- Chrome DevTools의 Memory 탭으로 메모리 누수를 디버깅할 수 있습니다.
