프로세스는 실행 중인 프로그램, 스레드는 프로세스 내의 실행 흐름 단위입니다.

| 특성 | 프로세스 | 스레드 |
|------|---------|--------|
| 메모리 | 독립된 메모리 공간 | 메모리 공유 |
| 생성 비용 | 높음 | 낮음 |
| 통신 | IPC (파이프, 소켓 등) | 공유 메모리 |
| 안정성 | 독립적 (하나 죽어도 다른 것에 영향 없음) | 하나 죽으면 전체 영향 |

**웹 브라우저 관점:**
- 각 탭은 별도 프로세스 (크래시 격리)
- JavaScript는 싱글 스레드 (이벤트 루프로 비동기 처리)
- Web Worker로 백그라운드 스레드 사용 가능

```javascript
// Web Worker - 별도 스레드에서 실행
const worker = new Worker('worker.js');
worker.postMessage({ data: heavyData });
worker.onmessage = (e) => console.log(e.data);
```

- JavaScript가 싱글 스레드인 이유: DOM 조작의 동시성 문제를 피하기 위해서입니다.
