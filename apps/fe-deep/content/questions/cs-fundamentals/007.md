데드락은 두 개 이상의 프로세스가 서로의 자원을 기다리며 **무한 대기**에 빠지는 상태입니다.

**데드락 발생 조건 (4가지 모두 충족 시):**
1. **상호 배제**: 자원을 동시에 사용할 수 없음
2. **점유 대기**: 자원을 보유한 채 다른 자원 대기
3. **비선점**: 강제로 자원을 뺏을 수 없음
4. **순환 대기**: 자원 대기가 원형으로 연결

**프론트엔드 유사 상황:**

1. **순환 의존성 (Circular Dependency):**
```javascript
// moduleA.js
import { b } from './moduleB';
export const a = b + 1;

// moduleB.js
import { a } from './moduleA';
export const b = a + 1; // undefined!
```

2. **상태 업데이트 무한 루프:**
```jsx
// BAD: useEffect에서 의존성인 state를 업데이트
useEffect(() => {
  setCount(count + 1); // 무한 리렌더링
}, [count]);
```

3. **Promise 체인 교착:**
```javascript
// A가 B를 기다리고, B가 A를 기다림
const a = async () => { await b(); };
const b = async () => { await a(); }; // Stack overflow
```

**해결:**
- 순환 의존성: 의존성 방향 정리, 중간 모듈 분리
- 무한 루프: useEffect 의존성 배열 검토
- ESLint `import/no-cycle` 규칙 활용
