Performance API는 정밀한 성능 데이터를 수집하는 브라우저 내장 API입니다.

**사용자 정의 마킹:**
```javascript
performance.mark('api-start');
await fetchData();
performance.mark('api-end');
performance.measure('API 호출', 'api-start', 'api-end');

const measure = performance.getEntriesByName('API 호출')[0];
console.log(`API 소요 시간: ${measure.duration}ms`);
```

**네비게이션 타이밍:**
```javascript
const nav = performance.getEntriesByType('navigation')[0];
console.log('DNS 조회:', nav.domainLookupEnd - nav.domainLookupStart);
console.log('TCP 연결:', nav.connectEnd - nav.connectStart);
console.log('TTFB:', nav.responseStart - nav.requestStart);
console.log('DOM 파싱:', nav.domContentLoadedEventEnd - nav.responseEnd);
```

**PerformanceObserver (실시간 감지):**
```javascript
const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    if (entry.entryType === 'largest-contentful-paint') {
      console.log('LCP:', entry.startTime);
    }
  }
});
observer.observe({ type: 'largest-contentful-paint', buffered: true });
```

- `web-vitals` 라이브러리가 이 API를 래핑하여 CWV 측정
- Lighthouse, Chrome DevTools Performance 탭도 내부적으로 사용
