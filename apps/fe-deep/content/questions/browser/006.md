URL 입력부터 화면 표시까지의 전체 과정입니다.

1. **DNS 조회**: 도메인명 → IP 주소 변환
   - 브라우저 캐시 → OS 캐시 → 라우터 → ISP DNS 서버
2. **TCP 연결**: 3-way handshake (SYN → SYN-ACK → ACK)
3. **TLS 핸드셰이크** (HTTPS인 경우): 암호화 연결 수립
4. **HTTP 요청**: GET / HTTP/1.1 전송
5. **서버 응답**: HTML 문서 반환
6. **HTML 파싱**: DOM 트리 구축
7. **CSS 파싱**: CSSOM 트리 구축
8. **JavaScript 실행**: DOM 조작, 이벤트 바인딩
9. **렌더 트리 생성**: DOM + CSSOM 결합
10. **Layout → Paint → Composite**: 화면에 최종 표시

- 이 과정에서 다양한 최적화가 적용됩니다: DNS 프리페치, 프리커넥트, HTTP/2 멀티플렉싱 등
- Service Worker가 있다면 네트워크 요청을 가로채 캐시된 응답을 반환할 수 있습니다.
