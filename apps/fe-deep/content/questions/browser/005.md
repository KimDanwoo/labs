두 속성 모두 JavaScript 파일을 비동기적으로 로드하지만, 실행 시점이 다릅니다.

```html
<!-- 기본: HTML 파싱을 멈추고 스크립트 다운로드 + 실행 -->
<script src="app.js"></script>

<!-- async: 다운로드는 비동기, 다운로드 완료 즉시 실행 (파싱 중단) -->
<script src="analytics.js" async></script>

<!-- defer: 다운로드는 비동기, HTML 파싱 완료 후 실행 -->
<script src="app.js" defer></script>
```

| 속성 | 다운로드 | 실행 시점 | 실행 순서 |
|------|---------|-----------|----------|
| 없음 | 동기(파싱 차단) | 즉시 | 순서 보장 |
| async | 비동기 | 다운로드 완료 즉시 | 순서 미보장 |
| defer | 비동기 | DOMContentLoaded 전 | 순서 보장 |

- **defer**: 앱의 메인 스크립트에 적합 (순서 보장, DOM 파싱 후 실행)
- **async**: 독립적인 스크립트(Google Analytics 등)에 적합
- 모듈 스크립트(`type="module"`)는 기본적으로 defer처럼 동작합니다.
