브라우저가 HTML을 받아 화면에 표시하기까지의 과정입니다.

1. **HTML 파싱 → DOM 트리 생성**
2. **CSS 파싱 → CSSOM 트리 생성**
3. **DOM + CSSOM → Render Tree 생성** (display:none 제외)
4. **Layout (Reflow)**: 각 요소의 크기와 위치 계산
5. **Paint**: 각 요소를 픽셀로 그리기
6. **Composite**: 레이어를 합성하여 최종 화면 표시

- **Reflow(리플로우)**: 요소의 크기/위치가 변경될 때 레이아웃을 다시 계산. 비용이 큽니다.
- **Repaint(리페인트)**: 색상 등 시각적 속성만 변경될 때. 리플로우보다 가볍습니다.
- CSS는 렌더링을 차단하므로 `<head>`에 배치합니다.
- JavaScript는 DOM 파싱을 차단할 수 있으므로 `<body>` 하단 또는 `defer`/`async` 사용을 권장합니다.
