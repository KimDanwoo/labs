requestIdleCallback(rIC)은 브라우저가 **유휴 상태일 때** 콜백을 실행합니다.

```javascript
requestIdleCallback((deadline) => {
  // deadline.timeRemaining(): 남은 유휴 시간 (ms)
  while (deadline.timeRemaining() > 0 && tasks.length > 0) {
    performTask(tasks.shift());
  }
  if (tasks.length > 0) {
    requestIdleCallback(processRemainingTasks); // 다음 유휴 시간에 계속
  }
}, { timeout: 2000 }); // 최대 2초 후에는 강제 실행
```

**스케줄링 우선순위:**
1. 사용자 입력 이벤트 (최우선)
2. requestAnimationFrame (렌더링 전)
3. 렌더링/페인팅
4. **requestIdleCallback** (유휴 시간)

**활용 사례:**
- 분석 데이터 전송 (비필수 네트워크 요청)
- 프리페칭 (다음 페이지 데이터 미리 로드)
- 비필수 DOM 업데이트
- 캐시 정리, 로깅

**React와의 관계:**
- React의 Concurrent Mode 내부 스케줄러가 유사한 원리로 동작
- `scheduler` 패키지에서 우선순위 기반 작업 스케줄링 구현

- Safari 미지원 → 폴리필 또는 setTimeout fallback 필요
