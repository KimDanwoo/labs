DOM 이벤트는 3단계로 전파됩니다.

1. **캡처링(Capturing)**: document → 부모 → 타깃 (하향)
2. **타깃(Target)**: 이벤트가 발생한 요소
3. **버블링(Bubbling)**: 타깃 → 부모 → document (상향)

```javascript
// 이벤트 위임 (Event Delegation)
// 자식 요소마다 이벤트를 등록하지 않고, 부모에 한 번만 등록
document.querySelector('.list').addEventListener('click', (e) => {
  const target = e.target as HTMLElement;
  if (target.matches('.item')) {
    console.log('클릭된 아이템:', target.textContent);
  }
});

// 버블링 중단
element.addEventListener('click', (e) => {
  e.stopPropagation(); // 상위로 이벤트 전파 중단
});

// 캡처링 단계에서 감지
element.addEventListener('click', handler, true); // 세 번째 인자 true
```

- **이벤트 위임 장점**: 동적으로 추가되는 요소도 처리 가능, 메모리 효율적
- React의 이벤트 시스템도 내부적으로 이벤트 위임을 사용합니다.
- `e.preventDefault()`는 기본 동작을 막고, `e.stopPropagation()`은 전파를 막습니다.
