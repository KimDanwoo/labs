Reflow는 레이아웃 재계산, Repaint는 화면 다시 그리기입니다.

**Reflow 발생 (비용 높음):**
- DOM 요소 추가/삭제
- 요소 크기/위치 변경 (width, height, margin, padding)
- 창 크기 변경
- 폰트 변경

**Repaint 발생 (비용 낮음):**
- 색상, 배경색 변경
- visibility, opacity 변경
- box-shadow 변경

```javascript
// 나쁜 예: 여러 번의 reflow 발생
element.style.width = '100px';
element.style.height = '200px';
element.style.margin = '10px';

// 좋은 예: 한 번의 reflow로 최적화
element.classList.add('new-style');
// 또는
element.style.cssText = 'width:100px; height:200px; margin:10px';
```

**최적화 방법:**
- DOM 조작을 최소화하고 일괄 처리합니다.
- `transform`, `opacity` 사용 (GPU 가속, reflow 없음)
- `will-change` 속성으로 브라우저에 변경 예고
- `requestAnimationFrame`으로 애니메이션 최적화
