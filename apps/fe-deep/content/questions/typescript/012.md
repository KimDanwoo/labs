타입 호환성에서 서브타입 관계가 어떻게 전파되는지를 설명하는 개념입니다.

**공변성(Covariance):** 서브타입 관계가 그대로 유지
```typescript
interface Animal { name: string; }
interface Dog extends Animal { breed: string; }

// 배열은 공변적: Dog[] → Animal[] 할당 가능
const dogs: Dog[] = [{ name: 'Rex', breed: 'Husky' }];
const animals: Animal[] = dogs; // OK

// 함수 반환 타입도 공변적
type GetAnimal = () => Animal;
type GetDog = () => Dog;
const getDog: GetDog = () => ({ name: 'Rex', breed: 'Husky' });
const getAnimal: GetAnimal = getDog; // OK
```

**반공변성(Contravariance):** 서브타입 관계가 역전
```typescript
// 함수 매개변수는 반공변적 (strict 모드)
type HandleAnimal = (animal: Animal) => void;
type HandleDog = (dog: Dog) => void;
const handleAnimal: HandleAnimal = (a) => console.log(a.name);
const handleDog: HandleDog = handleAnimal; // OK (역전)
```

**실무 영향:**
- `strictFunctionTypes` 옵션이 함수 매개변수의 반공변성 검사를 활성화
- 이벤트 핸들러 타입 할당 시 주의 필요
- 제네릭 타입 설계 시 in/out 위치 고려
