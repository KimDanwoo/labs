제네릭은 타입을 매개변수화하여 재사용 가능한 컴포넌트를 만드는 기능입니다. 함수, 클래스, 인터페이스에서 사용할 수 있습니다.

```typescript
// 제네릭 함수
function getFirst<T>(arr: T[]): T | undefined {
  return arr[0];
}

getFirst<number>([1, 2, 3]); // number 타입 반환
getFirst(['a', 'b']);         // string 타입 자동 추론

// 제네릭 인터페이스
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

type UserResponse = ApiResponse<{ name: string; email: string }>;

// 제네릭 제약 (extends)
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { name: 'Kim', age: 25 };
getProperty(user, 'name');  // OK: string
getProperty(user, 'email'); // Error: 'email'은 keyof User에 없음
```

- 제네릭은 **타입 안전성**과 **코드 재사용성**을 동시에 달성합니다.
- `extends`로 제네릭 타입에 제약을 추가할 수 있습니다.
- React에서 `useState<Type>()`, Props 타입 등에 널리 사용됩니다.
