requestAnimationFrame(rAF)은 브라우저 **렌더링 사이클에 동기화**된 애니메이션 API입니다.

```javascript
// 기본 애니메이션 루프
function animate(timestamp) {
  // timestamp: 페이지 로드 후 경과 시간 (ms)
  element.style.transform = `translateX(${timestamp * 0.1}px)`;
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);

// 프레임 레이트 제한 (30fps)
let lastTime = 0;
function animate30fps(timestamp) {
  if (timestamp - lastTime >= 33.33) { // 1000/30
    update();
    lastTime = timestamp;
  }
  requestAnimationFrame(animate30fps);
}
```

**rAF vs setTimeout/setInterval:**
| 특성 | rAF | setTimeout |
|------|-----|------------|
| 실행 타이밍 | 렌더링 직전 (약 16.67ms) | 정확하지 않음 |
| 탭 비활성 | 자동 일시정지 | 계속 실행 |
| 배터리 효율 | 좋음 | 나쁨 |
| 프레임 동기화 | O | X (jank 발생) |

**실무 활용:**
- 스크롤 이벤트 최적화: `onScroll` → rAF로 throttle
- 커스텀 애니메이션: CSS로 불가능한 복잡한 동작
- Canvas/WebGL 렌더 루프
- DOM 읽기/쓰기 분리: 강제 reflow 방지
