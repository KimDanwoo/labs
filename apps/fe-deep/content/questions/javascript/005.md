`this`는 함수가 **호출되는 방식**에 따라 동적으로 결정됩니다.

```javascript
// 1. 일반 함수 호출 → window(전역) 또는 undefined(strict)
function show() { console.log(this); }
show(); // window (non-strict)

// 2. 메서드 호출 → 해당 객체
const obj = { name: 'Kim', show() { console.log(this.name); } };
obj.show(); // 'Kim'

// 3. 생성자 호출 → 새 인스턴스
function User(name) { this.name = name; }
const user = new User('Lee'); // this → user 인스턴스

// 4. call/apply/bind → 명시적 바인딩
show.call({ name: 'Park' }); // this → { name: 'Park' }

// 5. 화살표 함수 → 상위 스코프의 this (렉시컬 바인딩)
const obj2 = {
  name: 'Choi',
  show: () => console.log(this), // 상위 스코프(전역)의 this
  showMethod() {
    const inner = () => console.log(this.name);
    inner(); // 'Choi' (상위 메서드의 this)
  }
};
```

- 화살표 함수는 자체 `this`를 갖지 않고 선언 시점의 상위 스코프 `this`를 사용합니다.
- React 클래스 컴포넌트에서 이벤트 핸들러의 `this` 바인딩 문제가 자주 출제됩니다.
