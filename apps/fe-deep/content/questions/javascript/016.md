Symbol은 **고유하고 변경 불가능한 원시 타입**으로, 주로 객체 속성의 키로 사용됩니다.

**기본 사용:**
```javascript
const id = Symbol('id');
const user = { [id]: 123, name: 'Kim' };

user[id]; // 123
Object.keys(user); // ['name'] — Symbol 키는 열거되지 않음
```

**Well-known Symbols (내장 심볼):**
```javascript
// Symbol.iterator — 객체를 iterable로 만들기
class Range {
  constructor(start, end) { this.start = start; this.end = end; }
  [Symbol.iterator]() {
    let current = this.start;
    const end = this.end;
    return {
      next() {
        return current <= end
          ? { value: current++, done: false }
          : { done: true };
      }
    };
  }
}
for (const n of new Range(1, 5)) console.log(n); // 1,2,3,4,5

// Symbol.toPrimitive — 타입 변환 커스텀
class Money {
  constructor(amount, currency) {
    this.amount = amount;
    this.currency = currency;
  }
  [Symbol.toPrimitive](hint) {
    if (hint === 'number') return this.amount;
    return `${this.amount} ${this.currency}`;
  }
}
```

**주요 Well-known Symbols:**
- `Symbol.iterator`: for...of 순회 정의
- `Symbol.asyncIterator`: for await...of 정의
- `Symbol.toPrimitive`: 타입 변환 동작 정의
- `Symbol.hasInstance`: instanceof 동작 커스텀

- 라이브러리에서 **속성 이름 충돌 방지**에 유용
- Redux 등에서 내부 식별자로 활용
