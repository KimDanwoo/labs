Proxy는 객체의 기본 동작을 **가로채서 커스텀 로직**을 실행합니다.

```javascript
const handler = {
  get(target, prop) {
    console.log(`[GET] ${prop}`);
    return Reflect.get(target, prop);
  },
  set(target, prop, value) {
    if (prop === 'age' && (value < 0 || value > 150)) {
      throw new RangeError('Invalid age');
    }
    return Reflect.set(target, prop, value);
  }
};
const user = new Proxy({ name: 'Kim', age: 25 }, handler);
```

**Reflect**: Proxy 트랩 내에서 원래 동작을 안전하게 실행하는 유틸리티

**프론트엔드 활용:**
1. **반응성 시스템**: Vue 3의 reactive()가 Proxy 기반
2. **유효성 검사**: 속성 변경 시 자동 검증
3. **로깅/디버깅**: 상태 변경 추적
4. **불변성 보장**: set 트랩에서 읽기 전용 객체 생성
5. **기본값 제공**: get 트랩에서 undefined 대신 기본값 반환

MobX도 내부적으로 Proxy 사용. Proxy는 폴리필 불가능합니다.
