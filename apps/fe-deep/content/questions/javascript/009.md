Iterator는 순회 프로토콜, Generator는 Iterator를 쉽게 만드는 특수 함수입니다.

**Iterator Protocol:**
```javascript
const range = {
  [Symbol.iterator]() {
    let current = 1;
    return {
      next() {
        return current <= 5 ? { value: current++, done: false } : { done: true };
      }
    };
  }
};
for (const n of range) console.log(n); // 1,2,3,4,5
```

**Generator Function:**
```javascript
function* fibonacci() {
  let [a, b] = [0, 1];
  while (true) {
    yield a;
    [a, b] = [b, a + b];
  }
}
const fib = fibonacci();
fib.next().value; // 0
fib.next().value; // 1
```

**실무 활용:**
1. 페이지네이션: yield로 각 페이지 데이터를 필요할 때만 fetch
2. 무한 스크롤 데이터 소스: 다음 청크를 lazy하게 생성
3. 비동기 흐름 제어: Redux-Saga가 Generator 기반
4. 유니크 ID 생성기

Generator는 실행을 일시 중단/재개할 수 있는 유일한 함수입니다.
