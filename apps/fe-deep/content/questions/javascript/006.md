JavaScript는 프로토타입 기반 언어로, 객체는 다른 객체를 프로토타입으로 참조하여 속성과 메서드를 상속받습니다.

```javascript
function Person(name) {
  this.name = name;
}

Person.prototype.greet = function() {
  return \`안녕하세요, \${this.name}입니다.\`;
};

const kim = new Person('Kim');
kim.greet(); // '안녕하세요, Kim입니다.'

// 프로토타입 체인
// kim → Person.prototype → Object.prototype → null
console.log(kim.hasOwnProperty('name')); // true
// hasOwnProperty는 Object.prototype에서 찾음
```

- 객체에서 속성을 찾을 때 자신 → 프로토타입 → 프로토타입의 프로토타입 순으로 탐색합니다.
- `__proto__`는 객체의 프로토타입 참조, `prototype`은 생성자 함수의 속성입니다.
- ES6의 `class` 문법도 내부적으로 프로토타입 기반으로 동작합니다.
- `Object.create()`로 직접 프로토타입을 지정한 객체를 만들 수 있습니다.
