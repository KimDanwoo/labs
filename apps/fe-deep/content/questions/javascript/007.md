세 메서드 모두 배열을 순회하며 새로운 결과를 반환하는 고차 함수입니다. 원본 배열을 변경하지 않습니다.

```javascript
const numbers = [1, 2, 3, 4, 5];

// map: 각 요소를 변환하여 새 배열 반환
const doubled = numbers.map(n => n * 2);
// [2, 4, 6, 8, 10]

// filter: 조건에 맞는 요소만 새 배열로 반환
const evens = numbers.filter(n => n % 2 === 0);
// [2, 4]

// reduce: 배열을 하나의 값으로 축소
const sum = numbers.reduce((acc, n) => acc + n, 0);
// 15

// 조합 사용 예시
const result = numbers
  .filter(n => n > 2)     // [3, 4, 5]
  .map(n => n * 10)       // [30, 40, 50]
  .reduce((a, b) => a + b, 0); // 120
```

- **map**: 배열의 각 요소를 변환할 때 (데이터 가공)
- **filter**: 조건에 맞는 요소를 선별할 때 (검색, 필터링)
- **reduce**: 배열을 하나의 값(합계, 객체 등)으로 만들 때
- React에서 JSX 리스트 렌더링 시 `map`이 매우 자주 사용됩니다.
