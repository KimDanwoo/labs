이벤트 루프는 JavaScript의 단일 스레드 환경에서 비동기 작업을 처리하는 메커니즘입니다.

**실행 순서:**
1. **Call Stack**: 동기 코드가 실행되는 곳
2. **Microtask Queue**: Promise, MutationObserver (우선 실행)
3. **Macrotask Queue**: setTimeout, setInterval, I/O

```javascript
console.log('1'); // 동기

setTimeout(() => console.log('2'), 0); // Macrotask

Promise.resolve().then(() => console.log('3')); // Microtask

console.log('4'); // 동기

// 출력 순서: 1, 4, 3, 2
```

- Call Stack이 비면 Microtask Queue를 먼저 모두 처리합니다.
- Microtask가 모두 처리된 후 Macrotask를 하나 실행합니다.
- 각 Macrotask 실행 후에도 Microtask Queue를 확인합니다.
- 이 원리를 이해하면 비동기 코드의 실행 순서를 예측할 수 있습니다.
