클로저는 함수가 선언될 때의 렉시컬 환경(Lexical Environment)을 기억하여, 함수가 자신의 스코프 밖에서 실행되더라도 그 환경에 접근할 수 있는 기능입니다.

```javascript
function createCounter() {
  let count = 0; // 외부 함수의 변수

  return {
    increment: () => ++count,
    getCount: () => count,
  };
}

const counter = createCounter();
counter.increment(); // 1
counter.increment(); // 2
counter.getCount();  // 2
// count 변수는 직접 접근 불가 → 데이터 은닉
```

- **데이터 은닉**: private 변수를 만들 수 있습니다.
- **상태 유지**: 함수 호출 간에 상태를 유지합니다.
- **주의점**: 클로저가 참조하는 변수는 GC되지 않으므로 메모리 누수에 주의해야 합니다.
- React의 `useState`, 이벤트 핸들러 등에서 클로저가 널리 사용됩니다.
