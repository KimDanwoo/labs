Promise는 비동기 작업의 결과를 나타내는 객체이고, async/await는 Promise를 더 직관적으로 사용하는 문법적 설탕(syntactic sugar)입니다.

```javascript
// Promise 체이닝
function fetchData() {
  return fetch('/api/data')
    .then(res => res.json())
    .then(data => {
      console.log(data);
      return data;
    })
    .catch(err => console.error(err));
}

// async/await (동일한 동작)
async function fetchData() {
  try {
    const res = await fetch('/api/data');
    const data = await res.json();
    console.log(data);
    return data;
  } catch (err) {
    console.error(err);
  }
}
```

- **async/await 장점**: 동기 코드처럼 읽히므로 가독성이 좋습니다.
- **에러 처리**: Promise는 `.catch()`, async/await는 `try/catch`를 사용합니다.
- **병렬 처리**: `Promise.all()`을 사용하면 여러 비동기 작업을 동시에 실행할 수 있습니다.

```javascript
// 병렬 처리
const [users, posts] = await Promise.all([
  fetch('/api/users').then(r => r.json()),
  fetch('/api/posts').then(r => r.json()),
]);
```
