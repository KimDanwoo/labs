세 가지 변수 선언 키워드는 스코프, 호이스팅, 재할당 측면에서 차이가 있습니다.

| 특성 | var | let | const |
|------|-----|-----|-------|
| 스코프 | 함수 | 블록 | 블록 |
| 호이스팅 | O (undefined) | O (TDZ) | O (TDZ) |
| 재선언 | O | X | X |
| 재할당 | O | O | X |

```javascript
// var: 함수 스코프, 호이스팅 시 undefined
console.log(a); // undefined
var a = 1;

// let: 블록 스코프, TDZ(Temporal Dead Zone)
console.log(b); // ReferenceError
let b = 2;

// const: 값 재할당 불가, 하지만 객체의 속성은 변경 가능
const obj = { name: 'Kim' };
obj.name = 'Lee'; // OK
obj = {};          // Error
```

- 현대 JavaScript에서는 `const`를 기본으로 사용하고, 재할당이 필요한 경우에만 `let`을 사용합니다.
- `var`는 예측하기 어려운 동작을 유발하므로 사용하지 않는 것이 권장됩니다.
