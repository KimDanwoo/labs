둘 다 React 18의 Concurrent 기능으로, **긴급하지 않은 업데이트의 우선순위를 낮춰서** 사용자 입력 같은 급한 업데이트가 무거운 렌더링에 막히지 않게 합니다.

### **useTransition**

**상태 업데이트 함수를 감싸서** "이 업데이트는 급하지 않다"고 표시합니다.

예를 들어 검색 입력에서 입력값 반영은 즉시 하고, 무거운 결과 목록 갱신은 `startTransition`으로 감싸면 — 타이핑이 계속 들어올 때 React가 진행 중이던 결과 렌더링을 버리고 입력부터 처리합니다.

`isPending` 값을 제공하므로 **지연 중임을 UI에 표시**할 수 있습니다.

### **useDeferredValue**

**값 자체의 지연된 사본**을 만듭니다. 원본 값은 즉시 바뀌고, 지연된 값은 급한 렌더링이 끝난 뒤에 따라옵니다.

setter에 접근할 수 없는 경우 — 예를 들어 **props로 받은 값**을 기준으로 무거운 목록을 렌더링할 때 적합합니다.

### **선택 기준**

- 상태 업데이트 코드를 **직접 감쌀 수 있으면** `useTransition`
- **값만 받아서** 쓸 수 있는 상황이면 `useDeferredValue`

### **디바운스와의 차이**

디바운스는 고정된 시간을 기다리지만, 이 둘은 **기기 성능에 적응**하고 새 입력이 오면 진행 중이던 렌더링을 즉시 폐기합니다. 기다리는 시간을 개발자가 정하지 않아도 됩니다.
