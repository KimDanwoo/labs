Custom Hook은 **컴포넌트 로직을 재사용 가능한 함수로 추출하는 패턴**입니다. `use`로 시작하는 이름을 가진 함수 안에서 다른 Hook을 조합해, 상태와 관련된 로직을 컴포넌트 밖으로 분리합니다.

### **왜 만드는가**

여러 컴포넌트에서 같은 로직 — 데이터 패칭, 이벤트 구독, 폼 상태 관리 — 이 반복될 때, 그 로직을 Custom Hook으로 추출하면 **컴포넌트는 "무엇을 하는지"만 남고 "어떻게 하는지"는 Hook 안에 캡슐화**됩니다.

예를 들어 API 패칭 로직을 `useFetch`로 추출하면, 로딩·에러·데이터 상태 관리와 요청 취소 처리를 한 곳에 두고 여러 컴포넌트가 한 줄로 가져다 쓸 수 있습니다.

### **Hook의 규칙**

- **최상위에서만 호출**합니다. 반복문·조건문·중첩 함수 안에서 호출하면 렌더링마다 Hook의 호출 순서가 달라져 React가 상태를 잘못 연결합니다.
- **React 함수 컴포넌트 또는 다른 Custom Hook 안에서만** 호출합니다.
- 이름은 반드시 **`use`로 시작**합니다. 린터가 이 규칙으로 Hook 여부를 판단해 위 규칙들을 검사합니다.

### **중요한 개념**

Custom Hook은 **상태 로직을 공유하지만 상태 자체를 공유하지 않습니다.**

같은 Hook을 두 컴포넌트에서 호출하면 각자 완전히 **독립적인 상태**를 가집니다. 상태를 공유하려면 Context나 외부 store가 필요합니다.
