폼 입력의 값을 **누가 관리하느냐**의 차이입니다.

### **Controlled Component**

**React state가 입력값의 유일한 출처(single source of truth)**입니다. 입력할 때마다 onChange로 state를 갱신하고, input은 그 state를 value로 받아 그립니다.

- 모든 입력 변화를 React가 알고 있으므로 **실시간 유효성 검사, 입력값 변형(포맷팅), 조건부 제출** 같은 세밀한 제어가 가능합니다.
- 대신 **입력마다 리렌더링**이 발생합니다.

### **Uncontrolled Component**

**DOM 자체가 값을 관리**하고, React는 필요한 시점에만 ref로 값을 읽습니다. 초기값은 `defaultValue`로 지정합니다.

- 입력 중에 리렌더링이 없어 가볍습니다.
- 제출 시점에만 값이 필요한 **간단한 폼**이나, 값 자체를 React가 가질 수 없는 **파일 입력**(`input type="file"`)에 적합합니다.

### **선택 기준**

실시간으로 값에 반응해야 하면 Controlled, 제출할 때만 읽으면 되면 Uncontrolled입니다. React 공식 문서는 대부분의 경우 **Controlled를 권장**하지만, 폼 필드가 많고 성능이 문제라면 React Hook Form처럼 **내부적으로 Uncontrolled 방식을 쓰는 라이브러리**로 리렌더를 줄이는 접근도 실무에서 많이 사용합니다.
