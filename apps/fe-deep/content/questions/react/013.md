Compound Components는 **여러 컴포넌트가 암묵적으로 상태를 공유하면서 하나의 UI 단위를 구성**하는 패턴입니다. HTML의 `select`와 `option`처럼, 부모와 자식이 세트로 동작하는 관계를 React로 표현한 것입니다.

### **어떤 모양인가**

셀렉트 박스를 예로 들면, `Select`가 최상위에 있고 그 아래 `Select.Trigger`, `Select.Options`, `Select.Option`을 사용자가 **원하는 구조로 직접 배치**합니다. 열림 상태나 선택값 같은 내부 상태는 부모가 갖고, 자식들은 그것을 암묵적으로 공유받습니다.

### **어떻게 구현하는가**

핵심은 **Context**입니다.

- 부모 컴포넌트가 상태(열림 여부, 선택값, 변경 함수)를 만들어 Context Provider로 감쌉니다.
- 각 서브 컴포넌트는 `useContext`로 그 상태를 꺼내 씁니다 — Trigger는 열림 토글, Option은 선택 처리처럼 각자의 역할만 수행합니다.
- 서브 컴포넌트를 `Select.Trigger`처럼 부모의 프로퍼티로 붙여 **한 세트임을 API로 드러냅니다.**

### **장점**

- **유연한 레이아웃** — 사용처가 마크업 구조를 직접 조립하므로, props 폭발 없이 다양한 변형을 만들 수 있습니다.
- **깔끔한 API** — 옵션을 배열 props로 욱여넣는 대신 JSX 구조 자체가 문서가 됩니다.
- **캡슐화** — 내부 상태 배선이 밖으로 드러나지 않습니다.

### **실제 사용**

Radix UI, Headless UI 같은 헤드리스 컴포넌트 라이브러리가 대부분 이 패턴으로 설계되어 있습니다.
