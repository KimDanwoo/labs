### **useState**

`useState`는 컴포넌트의 **상태를 React 내부에 저장하고 관리**하기 위한 Hook입니다.

setter 함수를 호출하면 상태값이 즉시 현재 렌더링에서 변경되는 것이 아니라, **상태 변경이 예약되고 컴포넌트가 다시 렌더링**됩니다.

변경된 상태값은 **다음 렌더링에서 반영**되며, 같은 이벤트 안에서 여러 상태 업데이트가 발생하면 React가 이를 **배칭(Batching)** 해서 불필요한 렌더링을 줄일 수 있습니다.

### **useEffect**

`useEffect`는 렌더링 이후 **외부 시스템과 동기화하거나 Side Effect를 처리**하기 위한 Hook입니다.

대표적으로 **API 호출, 이벤트 등록, 타이머, 구독 처리** 등에 사용합니다.

렌더링 결과가 **실제 DOM에 Commit된 이후 effect가 실행**되며, **의존성 배열**을 기준으로 다시 실행할지를 판단합니다.

- `[]` : **마운트 이후 1회 실행**
- `[dep]` : **dep이 변경될 때 실행**
- 생략 : **매 렌더링 이후 실행**

또한 effect에서 **cleanup 함수**를 반환하면, 해당 effect가 다시 실행되기 전이나 컴포넌트가 **언마운트될 때 cleanup이 실행**됩니다.

### **면접 답변**

**useState는 컴포넌트의 상태를 React 내부에 저장하고 관리하는 Hook**입니다. setter를 호출하면 상태 변경이 예약되고 컴포넌트가 다시 렌더링되며, **변경된 상태는 다음 렌더링에서 반영**됩니다. 또한 같은 이벤트 안에서 여러 상태 업데이트가 발생하면 **배칭을 통해 렌더링 횟수를 줄일 수 있습니다.**

**useEffect는 렌더링 이후 Side Effect를 처리하기 위한 Hook**입니다. API 호출이나 이벤트 등록, 타이머, 외부 시스템과의 동기화 등에 사용하며, **의존성 배열을 기준으로 effect의 재실행 여부가 결정**됩니다. 또한 cleanup 함수를 반환하면 **effect 재실행 전이나 컴포넌트 언마운트 시 정리 작업이 수행됩니다.**
