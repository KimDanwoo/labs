# 코모레비 — 여름빛 산책

작은 배낭을 멘 2등신 아이가 여름 시골을 돌아다니는 작은 탐험 게임입니다. 정교한 2D 배경화, Three.js 위에 합성한 선화 2D 캐릭터, 장소별 고정 카메라를 결합했습니다. 논길과 강이 있는 마을에서 길 끝으로 걸어가면 바닷길과 숲속 신사, 학교 운동장과 상점가로 이어집니다.

## 실행

저장소 루트에서 Node.js 24와 pnpm 9를 사용합니다.

```bash
pnpm install
pnpm --filter komorebi dev
```

http://localhost:3011 에 접속합니다. 다른 앱과 별도로 실행하는 신규 앱입니다.

## 조작

| 입력               | 동작                                                           |
| ------------------ | -------------------------------------------------------------- |
| WASD / 방향키      | 화면 기준 걷기                                                 |
| 길 클릭 / 터치     | 연결된 길을 따라 목적지로 걷기                                 |
| Shift              | 달리기                                                         |
| Space              | 점프                                                           |
| E / 장소 안내 버튼 | 그 시간대 추억 수집, 이미 모았으면 장소 행동(물수제비·방울 등) |
| M / 지도 버튼      | 지도와 그림일기 열기                                           |
| 지도 내 장소 선택  | 해당 장소까지 길안내 이동, 방향키로 중단                       |
| Escape             | 지도 / 추억 닫기                                               |
| 해 / 달 버튼       | 한낮 → 해 질 녘 → 밤 순환                                      |
| 구름 버튼          | 소나기 내리기 / 그치기                                         |
| 스피커 버튼        | 합성한 자연 소리·발소리·행동 소리 켜기                         |
| 카메라 버튼        | 현재 풍경을 PNG로 저장                                         |

모바일에서는 드래그 이동 패드와 달리기·점프 버튼을 사용할 수 있습니다. 지도에서 마을 입구로 돌아갈 수 있고, 모은 추억을 다시 읽을 수 있습니다. 여섯 장소는 한낮·해 질 녘·밤에 각각 다른 문장을 보여 주며, 시간대별 페이지가 localStorage에 따로 저장됩니다(18장). 이전 버전의 발견 기록은 낮 페이지로 이어집니다. 대화창과 지도가 열려 있으면 이동이 멈추고, 닫으면 길안내가 이어집니다.

## 검증과 배포 준비

```bash
pnpm --filter komorebi test       # 단위 테스트(node:test)
pnpm --filter komorebi lint       # 공유 next + FSD 규칙
pnpm --filter komorebi typecheck
pnpm --filter komorebi build
pnpm --filter komorebi test:e2e   # 브라우저 테스트 — build 후, 설치된 Chrome 사용
```

스타일 변경 전후 화면 비교: `SHOT_DIR=<폴더> pnpm --filter komorebi test:e2e e2e/visual.spec.ts`로 동작 줄이기 상태의 고정 화면 6장을 저장해 비교합니다. 색은 `src/app/globals.css`의 `:root` 팔레트(RGB 채널)를 `rgb(var(--이름) / 알파)`로만 씁니다.

`output: 'export'`를 사용하므로 빌드 결과인 `apps/komorebi/out/`을 정적 호스팅에 올릴 수 있습니다.

```bash
node apps/komorebi/e2e/serve.mjs apps/komorebi/out 3011
```

정적 내보내기 앱이므로 `next start`를 사용하지 않습니다.

## 구조와 표현 방식

- `app/`: Next 라우팅 진입점(layout·page·icon). 화면은 `src/views/walk/WalkView`에 위임
- `src/app/globals.css`: 게임 HUD 스타일
- `src/features/walk/ui`: HUD·지도·그림일기·추억·터치 조작 컴포넌트(`Walk`가 합성)
- `src/features/walk/model`: 엔진 수명주기·발견 기록·소리·단축키 훅, localStorage 저장소, 상수·타입
- `src/features/walk/lib/scene.ts`: 배경화 평면과 방향별 캐릭터 합성, 카메라, 이동, 지역 전환, 일시정지·렌더 예산
- `src/features/walk/lib/regionPlates.ts`: 지역 배경의 지연·순차 로딩과 해제(현재+이웃 지역만 유지, 요청 공유, 실패 시 재시도)
- `src/features/walk/lib/child.ts`: 승인된 후드 아이 원화의 4방향의 정지·보행·공중 원화 애니메이션
- `src/features/walk/lib/audio.ts`: Web Audio 바람과 지역별 물·파도·매미, 노을·밤의 풀벌레, 빗소리, 바닥별 발소리, 장소 행동 효과음
- `src/features/walk/lib/{placeEffects,sceneLife,fireflies,rain}.ts`: 장소 행동 효과, 나비·잠자리·갈매기·고양이, 반딧불, 빗줄기
- `src/shared/world/surfaces.ts`: 그림 속 바닥 재질(흙·돌·나무·모래) 구역
- `src/shared/world`: 그림 속 길에 맞춘 이동 영역, 지역 연결, 최단 경로
- `public/art`: 내장 이미지 생성 도구로 새로 제작한 여섯 장의 배경화
- `art-source`: 런타임에 쓰지 않는 생성 원본 그림(배포 제외 보관용)
- `scripts/*.test.ts`: 이동 영역·경로·렌더 예산·저장 데이터·추억 문장 단위 테스트
- `e2e/`: Playwright 브라우저 테스트(입력·일시정지·지역 로딩 대기/실패·노을 추억)

배경은 자유 회전하는 완전한 3D 지형이 아니라 고정 시점의 배경화입니다. 아이는 원화 스프라이트 시트를 사용하는 2D 캐릭터이며 거리별 크기, 옆모습·뒷모습, 움직이는 그림자로 입체감을 표현합니다. 모바일에서는 좁은 화면 밖으로 아이가 나가지 않게 가로 카메라가 따라갑니다. 논길과 다리처럼 화면에 보이는 길로 이동 범위를 제한합니다.

WebGL이 필요하며 기기 화면 배율을 최대 2로 제한합니다. 시스템의 동작 줄이기 설정을 지원합니다. 게임 이미지와 오디오는 외부 API 없이 로컬 자산과 합성으로 동작합니다. Google Fonts가 연결되지 않으면 시스템 글꼴을 사용합니다.

참고 게임의 원본 이미지나 모델을 사용하지 않습니다.

캐릭터는 실제 이동 거리로 보행 위상을 계산합니다. 정지 자세와 방향별 보행 프레임을 분리하고, 후드 중심과 발 높이를 정렬해 프레임 전환의 떨림을 줄였습니다. 달리기는 재생 속도와 상체 기울기가 달라집니다. 점프는 중력과 착지 반동을 사용하고, 공중에서 다시 점프할 수 없습니다. 학교 운동장에서는 넓은 영역을 자유롭게 뛰어다닐 수 있습니다.

캐릭터 동작 확인 영상: [걷기·달리기·점프](docs/character-motion.webm).

## 성능 관리

- 런타임 배경은 같은 해상도의 WebP(quality 88, effort 6), 캐릭터 시트는 픽셀이 동일한 lossless WebP(effort 6)를 사용합니다. PNG는 원본 보관용입니다.
- 시작 시에는 마을 배경과 캐릭터 시트 2장(1,296,954 bytes)만 기다립니다. 이웃 지역은 시작 후 한 장씩 받아 두고, 지역을 옮기면 현재·이웃·마을 밖의 배경 텍스처는 해제합니다. 아직 받지 못한 지역의 출구에서는 안내 후 기다렸다 넘어가고, 실패하면 현재 지역에 머문 채 출구를 벗어났다 들어오면 다시 시도합니다.
- 캐릭터는 4방향 × 8열 단일 시트를 UV 오프셋으로 바꿔 그립니다.
- 배경 mipmap을 만들지 않고, 터치 기기의 DPR 상한은 1.5입니다. 숨긴 탭에서는 RAF를 중단하고 복귀 시 시간 기준을 초기화합니다.
- 이동·점프 중이거나 카메라·노을·화면 전환이 자리를 잡는 동안만 60fps로 그리고(120Hz 화면에서도 상한 60), 그 밖에는 30fps로 그립니다. 지도·추억이 열리면 엔진이 일시정지합니다.
- 움직이지 않아 상태가 같으면 React 상태를 재발행하지 않습니다. 충돌 판정은 미리 계산한 선분과 거리의 제곱을 사용하며 기존 길 경계와의 동등성을 검사합니다.
- 사진 저장은 직전에 렌더링한 캔버스를 동기 복사하므로 상시 drawing buffer 보존이 필요하지 않습니다.

검증: 단위 테스트 68개, 브라우저 테스트 19개, lint, 타입 검사, 프로덕션 빌드. 이전 로컬 CPU 측정에서 충돌 판정 20만 회 중앙값은 97.46 ms → 38.03 ms였으며 기기별 FPS 향상을 의미하지 않습니다. 실기기 모바일 프레임 시간과 사진 저장은 별도 확인이 필요합니다.
