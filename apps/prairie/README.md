# 유니콘 러시 · Unicorn Rush

유니콘을 타고 초원과 하늘을 탐험하는 3D 비행 플레이그라운드.

사이트 표시 이름은 Unicorn Rush이며, 내부 앱 식별자와 배포 주소는 `prairie`를 유지한다.

**라이브:** https://prairie.danwoo.dev

---

## 개요

React Three Fiber 기반의 실시간 3D 씬. 러너 캐릭터가 무한 초원을 달리며, 키보드(데스크톱) 또는 터치 조이스틱(모바일)으로 이동 방향을 제어한다. 잔디·하늘·마을 오브젝트로 구성된 환경은 렌더링 성능을 유지하기 위해 인스턴싱과 청크 분할을 사용한다.

## 화면과 조작

- 짧은 곡면 풀잎 다발, 비대칭 수관과 가지, 세이지·올리브 색감으로 초원을 표현한다. 유니콘은 부드러운 몸체와 가는 꼬리 털, 자연색 무광 재질을 사용한다.
- 갈기·꼬리는 곡선 프레임을 따라 정점과 법선을 함께 변형하고, 뿌리에서 끝으로 밝아지는 은빛 털과 부드러운 섬유 반사를 사용한다. 야생화는 위로 휘어진 꽃잎과 금빛 꽃 중심을 정점색으로 표현한다.
- 감성 문구 없이 로고·조작법만 표시해 풍경을 감상할 공간을 확보한다. 크림색 로고·하단 키 가이드는 OS 테마와 무관하게 같은 대비를 유지한다. `풍경만 보기`로 HUD를 숨기고 `안내 보기`로 복원할 수 있다.
- 데스크톱: WASD 또는 방향키 이동, Shift 질주, Space 점프·길게 눌러 비행, 드래그로 시점 이동.
- 모바일: 화면을 끌어 이동하고 오른쪽의 질주·비행 버튼을 길게 누른다. 버튼에서 손을 떼거나 포인터가 취소되면 해당 입력을 해제한다.
- 로딩은 에셋 진행률과 첫 렌더 프레임을 모두 확인한 뒤 페이드아웃한다.

## 기술 포인트

- **빛과 재질**: 따뜻한 방향광과 차가운 하늘빛을 조합하고, 말과 날개는 실시간 자기 그림자와 지면 그림자를 만든다. 그림자 카메라는 말을 따라가며 데스크톱 2048·모바일 1024 해상도를 사용한다. 낮고 가는 풀, 작은 야생화, 곡면 수관과 색이 겹치는 먼 능선으로 원근감을 표현한다.

- **확장된 탐험과 주행 모션**: 강 사이 간격은 800m, 식생 셀 반경은 데스크톱 12·모바일 5다. 가까운 식생부터 기존 인스턴스 예산을 배정한다. 갤럽 발걸음에 맞춘 몸통 반동, 가감속 자세, 회전 기울기, 착지 반동과 지형 경사 적응을 적용한다. 속도가 높아지면 추적 카메라가 뒤로 빠지고 진행 방향을 더 멀리 바라보며, 프레임 시간에 맞춰 부드럽게 추적한다.
- **인스턴싱 잔디 + LOD**: 결정적 배치와 청크 재활용, 연속 밀도 LOD를 유지한다. 가까운 데스크톱 풀 다발은 곡면 잎 5개, 그 밖은 2개이며 추가 잎은 24~36m에서 축소되어 링 경계 전에 사라진다. 데스크톱 풀 1200/850/450, 모바일 650/650/450으로 기하 증가를 제어한다. 데스크톱 blade는 136m까지, 모바일은 72m까지 이어지고 그 너머는 지면 무늬·안개로 연결된다. 풀 높이·마른 잎의 색은 군집마다 다르고 바람은 공간적으로 이어지는 큰 파동과 작은 잎 떨림을 합친다.
- **한 가지 색 파이프라인**: 커스텀 셰이더(잔디·물·하상·헤이즈)도 마지막에 `tonemapping_fragment`/`colorspace_fragment`를 포함해 내장 머티리얼과 같은 ACES·sRGB 경로로 출력한다. 색은 전부 선형으로 섞는다(`new Color(hex)`가 선형으로 풀어준 값, 셰이더 리터럴은 표시색을 선형 변환해 굽는다). 그래서 잔디 blade가 녹아드는 지면색, 하상 강둑이 녹는 잔디색, 물이 멀어지며 닿는 안개색이 Ground 평면·씬 fog와 정확히 같은 색이 된다 — 예전엔 raw 출력이라 접합부마다 톤이 어긋났다.
- **지형 기복(하나의 높이 함수)**: `terrainHeightAt(x, z)` 사인 세 겹(진폭 4·2.5·1.2m, 최대 경사 ≈ 11°)을 바닥 평면 변위(GLSL, 같은 상수를 구움)·잔디 blade·나무·말·접지 그림자(경사 따라 기울임)가 전부 공유한다. 강 골 주변 25~70m는 0으로 눌러 하상·수면·강둑의 평지 전제를 지킨다(테스트로 고정). 바닥 평면은 정점 간격으로 스냅해 카메라를 따라가도 정점이 항상 같은 월드 지점을 샘플링한다(안 하면 기복이 꿈틀댄다). 카메라는 자기 자리 지형 위 최소 높이를 보장해 언덕 뒤에서 땅에 묻히지 않는다.
- **식생 인스턴싱과 충돌**: 휘어진 줄기·가지, 거친 곡면 수관 11개, 6단 침엽수, 바위, 부드러운 접지 음영을 다섯 InstancedMesh로 렌더링한다. 잎에는 불규칙한 명암과 바람을 적용한다. 기존 `floraInCell`의 결정적 배치와 충돌 함수를 유지한다. 모바일은 수관 지오메트리의 세분화를 낮춘다.
- **GLSL 잔디 셰이더**: ghibli-grass-v2(MIT, Wilson Ko)의 바람 버텍스 셰이더와 밑동→끝 색 그라데이션을 Next/Turbopack용 인라인 셰이더로 이식. 돌풍·거리 페이드·색 얼룩·말 회피·질주 돌풍 파동은 추가 튜닝.
- **유니콘 곡면 모델**: CC0 원본 `runner.glb`의 중복 정점을 용접하고 Loop subdivision 두 번을 적용한 `unicorn.glb`를 사용한다. 넓은 꼬리 판은 스키닝을 보존한 18개 털 다발로 교체한다. 17,913정점·35,552삼각형이며 뼈대와 원본 애니메이션을 그대로 유지한다. 곡선형 나선 뿔은 Head 뼈를 따라 움직이고, 비행 중에만 펼쳐지는 겹친 입체 깃털 날개는 어깨 뼈 위치를 따라간다. 원본 캐시를 직접 변경하지 않고 skeleton과 재질을 복제한다.
- **비행**: 공중에서 Space를 누르고 있으면 상승, 놓으면 활공 속도로 하강(공중에서는 다리를 접은 포즈), 고도 상한 32m. blade는 무작위로 0.15~0.45rad 기울여 두어 위에서 내려다봐도 면이 보인다(수직 평면이면 모서리만 보여 잔디가 사라진다). 카메라가 고도를 따라 오르고, 떠 있으면 발밑 잔디는 눕지 않는다.
- **제로백**: 고도 2.5m 이상에서 Q 또는 모바일 제로백 버튼으로 발동한다. 0.18초에 100km/h(27.78m/s)에 도달하며, 1.2초 동안 가속·유지·감속한다. 별빛 궤적과 FOV 확장으로 속도감을 표현하고, 회전 스킬과 동시 사용 가능하다. 종료 후 재사용 대기는 3초다.
- **공중 회전**: 고도 2.5m 이상에서 E 또는 모바일 회전 버튼으로 0.9초 배럴 롤을 발동한다. 몸통 중심으로 한 바퀴 돌며 별가루가 양쪽으로 흩어진다. 카메라는 회전하지 않고, 회전 중에는 하강을 멈춘다. 종료 후 1.5초 재사용 대기, 누르고 있어도 자동 재발동하지 않는다.
- **질주·점프**: Shift 질주는 최고속도 ×1.6에 FOV가 벌어지고, 발동 순간 말에서 퍼지는 돌풍 파동이 잔디를 쓸고 지나가며(잔디 버텍스 셰이더 유니폼), 발굽에서 금빛 잔광(`SprintTrail`, additive)이 뒤로 흩날린다. 잔디는 질주 여부와 무관하게 말 주변 2.6m에서 말을 피해 눕는다. Space 점프는 포물선 홉(≈1.4m), 공중에선 물보라가 멈추고 물에 착지하면 한 번 크게 터진다.
- **GLTF 러너 애니메이션**: 대기→걷기→갤럽을 속도에 따라 혼합하고 공중에서는 다리를 접은 점프 포즈로 전환한다. 뒤로 걸을 때는 걷기 클립을 역재생한다. 가중치 전환·회전 기울기·날개 펼침은 delta 기반 감쇠를 사용하며 프레임별 React 리렌더는 없다. 모델 스케일 0.55에 맞춰 카메라, 최고속도와 가속을 조정한다.
- **모바일/데스크톱 품질 분기**: `pointer: coarse` 미디어 쿼리로 기기를 감지해 DPR과 잔디 블레이드 수를 각각 조정한다.
- **터치 조이스틱**: 손 댄 자리에 조이스틱이 생기는 방식(`onPointerDown` 기준점 동적 생성). `pointer-coarse` 환경에서만 렌더링.
- **무한 반복 강**: Z축으로 무한한 강 골. 하상·수면 메시가 Z로 카메라를 따라가고 X는 가장 가까운 강 중심에 스냅한다 — 반복 주기(800)가 안개 시야(360×2)보다 넓어 화면에 강이 둘 이상 들어오지 않는 덕에 한 세트로 무한 반복이 성립한다. 강 기하(위치·하상 프로파일)는 `RIVER_GLSL` 하나를 Ground 구멍(`onBeforeCompile` discard), 하상 변위, 수심 계산이 공유하고, JS 쪽 같은 식(`riverBedDepthAt`)을 말의 y와 감속에 쓴다(중앙 수심 1.5m, 수심 비례 감속). 유니폼 갱신 없이 순수 수식. 물속을 달리면 수면이 말에 반응한다 — 물 셰이더가 말 위치·방향·속도 유니폼으로 뱃머리 파도(높이)와 V자 거품 항적(색·알파)을 그리고, `WadeSplash`가 속도 방향으로 늘어난 물보라(InstancedMesh 256개, 포물선 낙하, 수면 아래 소멸)와 퍼져나가는 파문 링을 얹는다. 말 상태는 `runnerState`(r3f 내부 공유 객체, 리렌더 없음)로 흘린다.
- **물 셰이더**: 하늘 큐브맵(`scene.background`)을 `samplerCube`로 받아 슐릭 프레넬로 비춘다 — 내려다보면 맑아 자갈이 비치고, 스치는 각에서는 하늘·구름이 반사된다. 추가 렌더 패스 없음. 파도 세 겹이 하류로 흐르고 유한차분 노멀로 태양 글린트, 수심 0 근처엔 거품선. 자갈 하상은 3×3 보로노이 프로시저럴(텍스처 없음) + 깊이 AO + 젖은 띠 + 물속 커스틱.
- **비네트**: 별도의 포스트프로세싱 없이 CSS 비네트와 상하 그라데이션으로 안내 글자의 대비를 유지한다.
- **강 방위 계산 (현재 HUD에서 숨김)**: 강은 안개 밖이거나 잔디에 가려 보이지 않을 때가 많아 화면 안내가 길잡이다. 카메라 yaw에서 화면 기준 방위(앞·뒤·좌·우)와 거리를 계산해 `rideStore`(외부 스토어)로 DOM HUD에 넘긴다 — r3f 루트와 DOM 루트가 달라 컨텍스트를 쓸 수 없다. `풍경만 보기`로 안내를 숨길 수 있다.
- **Three.js Fog + 지평선 헤이즈 + 능선**: fog는 기기별(데스크톱 85→360, 모바일 36→140). 잔디 blade가 지면색에 완전히 녹은(66m) 뒤의 평지를 능선 밑동까지 잇는 역할이라 청크 끝(72m)을 가릴 필요가 없다. 단색 fog 바닥과 그라데이션 큐브맵 하늘 사이의 선은 카메라를 따라다니는 원통(`Haze`)이 fog색→투명으로 녹여 지우고, 같은 원통 셰이더가 먼 능선 실루엣 3겹을 그린다 — 둘레 좌표의 주기적 값 노이즈(셀 수가 정수라 이음새 없음)를 능선형으로 접고, 겹마다 색·높이를 달리해 대기 원근을 낸다(멀수록 높고 하늘색). 원통이 카메라를 따라다니되 회전하지 않아 능선은 월드 방위에 고정되고 시차가 0 → 수 km 밖 산으로 읽힌다. 출력은 `tonemapping_fragment`/`colorspace_fragment`를 포함해 내장 머티리얼과 같은 ACES·sRGB 경로를 탄다. 바닥 평면은 100×100로 분할한다 — fog 깊이가 정점에서 보간되므로 1400m 삼각형 2개면 원경이 덜 안개 낀 채 대각선 경계가 생긴다(공중에서 확연).

## 구조

FSD(Feature-Sliced Design) 기반.

```
src/
  app/providers/          # 전역 프로바이더
  views/ride/RideView     # 단일 뷰 — SceneCanvas·Hud·TouchControls 조립
  widgets/
    scene/                # SceneCanvas(R3F Canvas), SceneLoader, ReadySignal
    hud/                  # 강 방위·키 안내 오버레이 (KeyCap)
  features/
    runner-control/       # 키보드·터치 입력 → RunnerRig 카메라 추적
  entities/
    grass/                # GrassField (청크 관리), GrassChunk (InstancedMesh)
    river/                # River (무한 반복 강 — 물 셰이더 + 강변)
    runner/               # Runner (GLTF + 애니메이션 블렌딩)
    scenery/              # Sky(큐브맵), Haze(지평선), Ground(무한 바닥 + 강 구멍 + 잔디 무늬)
  shared/
    config/               # 씬 상수 (카메라·안개·조명·색)
    lib/                  # useCoarsePointer 훅
    r3f/                  # rideStore(HUD), runnerState(말 상태), sceneReady
```

`runner.glb`는 재현 가능한 원본으로 보존한다. 생성한 `unicorn.glb`도 커밋하므로 배포에서 별도 모델 빌드가 필요 없다. 테스트는 지형·강·LOD 불변식과 함께 파생 모델의 뼈대·애니메이션 보존, 가중치 정규화, 법선·인덱스 및 삼각형 예산을 확인한다.

## 초원 탐험

출발점 앞 바람의 나무, 꽃잠 정원, 노을의 문을 발견할 수 있다. 주변에 도착하면 발견 카드가 나타나며 HUD의 발견 기록에서 다시 볼 수 있다. 첫 빛 고리를 +Z 방향으로 통과하면 7개 고리로 구성된 바람길이 시작된다. 고리는 순서대로 통과하며, 코스 나가기 또는 완주 후 다시 도전으로 초기화한다. 발견과 최고 기록은 `prairie.exploration.v1` 키로 브라우저에 저장한다. 저장 공간을 사용할 수 없어도 플레이는 계속된다. 풍경만 보기에서는 탐험 HUD도 숨긴다.

바람길 고리는 지면 위 21~28m에 배치한다(비행 상한 32m). 금빛·진주빛 후광, 서로 반대로 흐르는 빛 조각, 공전하며 반짝이는 별가루를 하나의 투명 셰이더 평면으로 표현한다. 다음 고리는 밝게, 이후 고리는 은은하게 표시한다.

## 살아 있는 초원

- 바람의 나무는 휘어진 줄기·뿌리·넓은 가지와 흔들리는 수관, 흩날리는 은빛 잎을 가진다. 가까이 가면 잎의 흐름이 빨라지고, 수관 주변 새들은 비행 중 접근에 반응한다.
- 꽃잠 정원은 기울어진 돌기둥과 덩굴, 잎, 다섯 꽃 군락으로 구성한다. 나비는 접근하면 날아올랐다가 위험이 사라지면 천천히 내려온다.
- 노을의 문은 어긋난 돌 블록과 떠 있는 돌조각을 가진다. 아치 개구부를 어느 방향으로든 통과하면 곡선 문양이 밝아지고 별가루가 위로 퍼진다. 고속 이동도 선분 통과로 판정하며 3초 재발동 간격을 둔다.
- 초원에는 풀을 뜯는 양과 땅에서 날아오르는 새, 강둑에는 잠자리를 배치한다. 반응은 거리·고도를 고려하고 잠시 경계하다가 진정한다. 먼 개체만 주변 월드에 재배치하며 강 골에 양을 배치하지 않는다.
- 생물은 종류별 인스턴싱으로 렌더링한다. 모바일은 양 4마리·각 날개 무리 10마리·은빛 잎 28개, 데스크톱은 각각 8·22·64개다. 프레임 업데이트는 ref와 인스턴스 행렬을 사용한다.
