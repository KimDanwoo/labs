# Golden Meadow lighting

`golden-meadow-1k.hdr` and `golden-meadow-2k.hdr` are the unmodified 1K and 2K HDR versions of **Kloppenheim 06 (Pure Sky)** by Greg Zaal (original) and Jarod Guest (sky edits), provided by Poly Haven.

- Asset: https://polyhaven.com/a/kloppenheim_06_puresky
- Download: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/2k/kloppenheim_06_puresky_2k.hdr
- License: CC0 1.0 — https://polyhaven.com/license

Served locally for environment lighting and material reflections. The same HDR image lights the materials and draws the visible sky; no third-party request is made during a ride.

Touch devices request only the 1K file (about 1.1 MiB); desktop uses 2K (about 4.2 MiB).
