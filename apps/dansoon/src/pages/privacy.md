이 블로그(danwoo.dev, log.danwoo.dev)는 회원가입이나 입력 양식이 없어서 방문자의 개인정보를 직접 수집하지 않아요. 다만 광고, 댓글, 호스팅을 위해 아래 외부 서비스를 쓰고 있고, 이 서비스들이 쿠키 등으로 정보를 처리할 수 있어요.

## 광고

### Google AdSense

- Google을 포함한 제3자 공급업체는 쿠키를 사용해, 방문자가 이 사이트나 다른 사이트를 방문한 기록을 바탕으로 광고를 보여줘요.
- Google은 광고 쿠키를 사용해 이 사이트와 인터넷의 다른 사이트 방문 기록에 맞춘 광고를 보여줄 수 있어요.
- 맞춤 광고는 [Google 광고 설정](https://adssettings.google.com)에서 끌 수 있어요. 다른 제3자 공급업체의 맞춤 광고 쿠키는 [aboutads.info](https://www.aboutads.info/choices/)에서 거부할 수 있어요.
- 자세한 내용은 [Google이 파트너 사이트의 정보를 사용하는 방법](https://policies.google.com/technologies/partner-sites)에서 볼 수 있어요.

### 카카오 애드핏

카카오 애드핏 광고가 함께 표시될 수 있어요. 카카오는 광고를 보여주고 효과를 측정하기 위해 쿠키 등으로 정보를 처리할 수 있어요. 자세한 내용은 [카카오 개인정보처리방침](https://www.kakao.com/policy/privacy)에서 볼 수 있어요.

## 댓글

댓글은 GitHub Discussions를 쓰는 giscus로 남겨요.

- 댓글을 쓰려면 GitHub 계정으로 로그인해야 해요.
- 남긴 댓글과 GitHub 사용자 이름은 GitHub 저장소([KimDanwoo/dansoon-comments](https://github.com/KimDanwoo/dansoon-comments))에 공개로 저장돼요.
- 댓글은 GitHub에서 직접 고치거나 지울 수 있고, 아래 이메일로 삭제를 요청할 수도 있어요.
- GitHub의 정보 처리는 [GitHub 개인정보 처리방침](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)을 따라요.

## 호스팅

이 블로그는 Vercel에서 운영돼요. 서비스 제공과 보안을 위해 Vercel이 IP 주소, 브라우저 정보 같은 접속 기록을 처리할 수 있어요. 자세한 내용은 [Vercel 개인정보처리방침](https://vercel.com/legal/privacy-policy)에서 볼 수 있어요.

## 브라우저에 저장하는 정보

밝은 화면·어두운 화면 설정은 방문자의 브라우저에만 저장되고, 서버로 보내지 않아요.

## 쿠키를 거부하려면

브라우저 설정에서 쿠키 저장을 막거나 지울 수 있어요. 쿠키를 막아도 글을 읽는 데는 문제가 없지만, 댓글처럼 로그인이 필요한 기능은 동작하지 않을 수 있어요.
